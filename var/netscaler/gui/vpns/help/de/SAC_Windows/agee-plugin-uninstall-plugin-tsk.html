Deinstallieren des Access Gateway Plug-ins

Sie können das Access Gateway Plug-in in der Systemsteuerung unter Software deinstallieren. Um das Plug-in zu deinstallieren, müssen Sie als Administrator angemeldet sein.
  1. Klicken Sie auf Start > Systemsteuerung.
  2. Klicken Sie auf Software.
  3. Klicken Sie unter Zurzeit installierte Programme auf Citrix Access Gateway Plug-in und dann auf Entfernen.
