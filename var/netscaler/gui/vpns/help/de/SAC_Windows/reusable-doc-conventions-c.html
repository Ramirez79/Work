Typografische Konventionen

In der Citrix Produktdokumentation werden folgende typografische Konventionen verwendet.

Darstellung oder Konvention Beschreibung
Steuerelemente in der Benutzeroberfläche Namen von Schaltflächen, Textfeldern, Optionen oder anderen Steuerelementen in der Benutzeroberfläche.
Befehlsnamen Namen von Befehlen, z. B. ipconfig.
Namen von Variablen Platzhalter für Informationen, die Sie eingeben. Beispielsweise bedeutet Dateiname, dass Sie den Namen der Datei eingeben.
Begriffe Neu eingeführt oder hervorgehobene Begriffe.
Codebeispiele In Code oder einer Textdatei angezeigter Text.
{geschweifte Klammern} Eine Reihe von Elementen, von denen eines in Befehlsanweisungen erforderlich ist. Beispiel: {Ja | Nein } bedeutet, dass Sie entweder "Ja" oder "Nein" eingeben müssen. Geben Sie die Klammern selbst nicht mit ein.
[eckige Klammern] Optionale Elemente in Befehlsanweisungen. Zum Beispiel bedeutet [/ping], dass Sie /ping zusammen mit dem Befehl eingeben können. Geben Sie die eckigen Klammern selbst nicht mit ein.
| (vertikaler Strich) Ein Trennzeichen zwischen Elementen in geschweiften oder eckigen Klammern in Befehlsanweisungen Zum Beispiel bedeutet { /hold | /release | /delete }, dass Sie /hold oder /release oder /delete eingeben
... (Auslassung) Die vorherigen Elemente in Befehlsanweisungen können wiederholt werden. Zum Beispiel bedeutet /route:Gerätename[,…] dass Sie zusätzliche Gerätenamen eingeben können, die durch Kommas getrennt werden.
