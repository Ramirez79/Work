Access Gateway Plug-in für Windows-Benutzerdokumentation

Bevor Sie sich mit dem Citrix Access Gateway Plug-in für Windows anmelden, sollten Sie in dieser Dokumentation nachlesen, wie Ihre Verbindungen funktionieren und wie Sie auf Netzwerkressourcen im gesicherten Netzwerk zugreifen.

Diese Benutzerdokumentation richtet sich an Benutzer, die sich am internen Netzwerk über ein Access Gateway-Gerät anmelden. Diese Dokumentation setzt voraus, dass das Access Gateway mit einem vorhandenen Netzwerk verbunden ist und dass Ihr Systemadministrator das Gerät für Benutzerverbindungen konfiguriert hat.
