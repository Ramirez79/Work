Hinzufügen von Lesezeichen auf der Registerkarte "Home"

Der Systemadministrator kann dem Access Interface Lesezeichen hinzufügen. Diese Lesezeichen werden als Links unter Unternehmenswebsites angezeigt.Sie können außerdem eigene Lesezeichen für Netzwerkressourcen erstellen, auf die Sie häufig zugreifen. Diese Lesezeichen können Links zu Intranetsites, z. B. eine SharePoint-Site, zu Internetwebsites oder auch Dateifreigaben im internen Netzwerk sein. Die von Ihnen erstellten Links werden unter Persönliche Websites angezeigt.

  1. Klicken Sie auf Hinzufügen.
  2. Geben Sie in Name den Namen für den Link ein.
  3. Geben Sie in Adresse die Webadresse der Website oder den Netzwerkpfad zum internen Webserver ein.
  4. Geben Sie in Beschreibung eine Beschreibung für den Link ein und klicken Sie dann auf Hinzufügen.
Anmerkung: Access Gateway unterscheidet automatisch zwischen Webadressen und Netzwerkdateipfaden anhand des Formats, in dem sie eingegeben werden, z. B. http://www.Unternehmen.com oder \\Server\Freigabename. Beim Erstellen eines Links brauchen Sie den Ressourcentyp nicht angeben.

Entfernen eines Lesezeichens

Sie können unter Persönliche Websites aufgelistete Lesezeichen entfernen, aber nicht die Links unter Unternehmenswebsites.

  1. Klicken Sie auf Entfernen.
  2. Wählen Sie das Lesezeichen aus und klicken Sie auf Entfernen.

Verwenden der Registerkarte "E-Mail"

Die Registerkarte "E-Mail" gibt Ihnen Zugriff auf Ihre E-Mail über Microsoft Outlook Web Access. Wenn Sie auf die Registerkarte klicken, wird Ihre E-Mail so angezeigt, als würden Sie eine lokale Version von Outlook verwenden.

Um Outlook Web Access zu verwenden, muss der Systemadministrator die Anwendung konfigurieren.

Verbinden mit Dateifreigaben über die Registerkarte "Dateiübertragung"

Auf der Registerkarte Dateiübertragung können Sie sich am internen Netzwerk anmelden und auf freigegebene Ressourcen zugreifen.

  1. Klicken Sie im Access Interface auf die Registerkarte Dateiübertragung.

Öffnen der Registerkarte "Dateiübertragung" über das Access Gateway-Symbol

  1. Klicken Sie im Infobereich mit der rechten Maustaste auf das Access Gateway-Symbol und klicken Sie dann auf Dateien übertragen.

In den folgenden Abschnitten werden die verschiedenen Komponenten der Registerkarte Dateiübertragung erklärt.

Konfigurieren der Einstellungen im oberen Bereich

Im oberen Bereich des Browserfensters gibt es mehrere Schaltflächen, mit denen Sie verschiedene Aufgaben zum Speichern und Übertragen von Dateien durchführen können.

  • Anmelden: Klicken Sie auf diese Schaltfläche, um sich am internen Netzwerk oder an einem bestimmten Computer im Netzwerk anzumelden.
  • Übergeordnet: Klicken Sie auf diese Schaltfläche, um zum vorigen Ordner zu navigieren.
  • Aktualisieren: Klicken Sie auf diese Schaltfläche, um die Inhalte des aktiven Ordners zu aktualisieren.
  • Neuer Ordner: Klicken Sie auf diese Schaltfläche, um einen neuen Ordner zu erstellen.
  • Download: Klicken Sie auf diese Schaltfläche, um die ausgewählte Datei vom Remoteserver herunterzuladen.
  • Upload: Klicken Sie auf diese Schaltfläche, um die ausgewählte Datei vom Benutzergerät in einen Ordner auf dem Remoteserver hochzuladen.
  • Löschen: Klicken Sie auf diese Schaltfläche, um die ausgewählte Datei auf dem Remotecomputer zu löschen.
  • Umbenennen: Klicken Sie auf diese Schaltfläche, um den Namen einer Datei oder eines Ordners zu ändern.
  • Abmelden: Klicken Sie auf diese Schaltfläche, um die Verbindung mit dem Remoteserver zu trennen.

Anzeigen von Ordnern und Dateien im linken Bereich

Die Server, die jeweiligen Verzeichnisse und die Verzeichnisstruktur werden im linken Bereich als Baum angezeigt. Klicken Sie auf das Pluszeichen (+), um Ordner anzuzeigen.

Verbinden zu Netzwerkressourcen im rechten Bereich

Im rechten Bereich wird das Fenster "Dateiserver" angezeigt. Melden Sie sich in diesem Fenster an einem Dateiserver im internen Netzwerk an. Um auf den Dateiserver zuzugreifen, geben Sie die Adresse der Dateifreigabe ein. Sie können auch Ihren Benutzernamen, Ihr Kennwort und den Domänennamen eingeben, falls erforderlich. Falls Sie nach der Anmeldung am Access Gateway Zugriff auf die Dateifreigabe haben, brauchen Sie unter Umständen Ihren Benutzernamen, Ihr Kennwort oder den Domänennamen nicht eingeben.

  1. Klicken Sie im Infobereich mit der rechten Maustaste auf das Access Gateway-Symbol und klicken Sie dann auf Dateien übertragen.
  2. Geben Sie in Adresse den Namen der Dateifreigabe ein.
  3. Wenn Anmeldeinformationen erforderlich sind, klicken Sie auf Anmeldeinformationen eingeben und führen Sie die Schritte 4 bis 7 durch. Klicken Sie andernfalls auf Anmelden.
  4. Geben Sie in Benutzername Ihren Benutzernamen ein.
  5. Geben Sie in Kennwort Ihr Kennwort ein.
  6. Geben Sie in Domäne einen gültigen Domänennamen ein.
  7. Klicken Sie auf Anmelden.

Falls der Remoteserver keiner bestimmten Domäne zugewiesen ist, lassen Sie das Feld Domäne leer.

Anmerkung: Wenn Sie dieses Feld leer lassen, werden Sie am internen Netzwerk und nicht an einem bestimmten Server angemeldet.

Im rechten Bereich werden jetzt die Unterordner und Dateien angezeigt. Der Speicherort des aktiven Ordners wird im Feld Adresse angezeigt.
