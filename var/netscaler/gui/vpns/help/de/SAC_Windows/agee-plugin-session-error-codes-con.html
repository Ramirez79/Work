Access Gateway-Sitzung: Fehlercodes

Die folgenden Fehlercodes werden im Access Gateway-Sitzungsfenster angezeigt. Diese Codes können bei der Behandlung von Problemen mit Access Gateway verwendet werden.

Fehlercode Beschreibung

0001–1000

Normalbetrieb

1001–2000

Interner Fehler

2001–3000

Access Gateway Plug-in-Fehler

3001–4000

Browserfehler

In der folgenden Tabelle finden Sie die Fehlercodes und Meldungen, die für eine Access Gateway-Sitzung angezeigt werden, sowie Hinweise, wie Sie auf die Meldungen reagieren.

Code Meldung Erklärung Aktion
0001 Laden... Diese Meldung gibt an, dass das Access Gateway Plug-in die Konfiguration lädt, bevor die Access Gateway-Sitzung hergestellt wird. Keine
0002 Verbindung aufgebaut. Klicken Sie zum Beenden der Sitzung mit der rechten Maustaste auf das Symbol "Access Gateway" und klicken Sie auf "Abmelden". Diese Meldung wird angezeigt, wenn das Access Gateway Plug-in eine Verbindung erfolgreich hergestellt hat. Keine
0003 Beenden... Diese Meldung wird angezeigt, wenn der Benutzer im Access Gateway-Menü auf Abmelden klickt. Keine
0004 Ihre Sitzung hat das Zeitlimit überschritten und Sie sind nicht verbunden. Diese Fehlermeldung wird angezeigt, wenn die Benutzergerätsitzung das Zeitlimit überschritten hat. Keine
0004 Sie sind nicht angemeldet. Diese Fehlermeldung wird angezeigt, wenn das Access Gateway Plug-in nicht verbunden ist. Keine
0005 Die Sitzung überschreitet in <Zahl> Sekunden das Zeitlimit. Diese Fehlermeldung wird angezeigt, wenn für eine Sitzung ein erzwungenes Zeitlimit konfiguriert wurde. Keine
0006 Downgrade des Citrix Access Gateway Plug-ins von <Versionsnummer> auf <Versionsnummer>. Access Gateway installiert eine frühere Version der Software. Keine
0006 Upgrade des Citrix Access Gateway Plug-ins von <Versionsnummer> auf <Versionsnummer>. Das Access Gateway Plug-in wird auf eine neuere Version der Software aktualisiert. Keine
1003 Speicherzuordnung fehlgeschlagen. Das Access Gateway Plug-in hat nicht genügend Speicher. Wenn dieser Fehler angezeigt wird, melden Sie sich ab, starten Sie das Access Gateway Plug-in neu und melden Sie sich wieder an. Melden Sie diesen Fehler auch Ihrem Helpdesk oder Systemadministrator.
1004 Es ist ein interner Fehler aufgetreten. Weitere Informationen erhalten Sie von Ihrem Administrator. Das Access Gateway Plug-in kann die Windows-API nicht erfolgreich aufrufen. Keine
1006 Es ist ein interner Fehler aufgetreten. Weitere Informationen erhalten Sie von Ihrem Administrator. Die Benutzergerätsicherheitsprüfung ist beim Scannen der Windows-Prozessliste fehlgeschlagen. Melden Sie sich mit einem Administratorkonto an.
1007 Es ist ein interner Fehler aufgetreten. Weitere Informationen erhalten Sie von Ihrem Administrator. Die Benutzergerätsicherheitsprüfung ist beim Öffnen eines Windows-Systemdienstes fehlgeschlagen. Melden Sie sich mit einem Administratorkonto an.
1008 Es ist ein interner Fehler aufgetreten. Weitere Informationen erhalten Sie von Ihrem Administrator. Das Access Gateway Plug-in ist fehlgeschlagen. Starten Sie das Access Gateway Plug-in neu und senden Sie die Debugtracingdatei an Ihren Helpdesk oder Systemadministrator.
1010 Die Anmeldung ist fehlgeschlagen. Der Benutzer konnte sich nicht anmelden. Keine
1011 Das Herunterladen der korrekten Konfiguration durch das Citrix Access Gateway Plug-in ist fehlgeschlagen. Das Access Gateway Plug-in kann die Access Gateway-Konfiguration nicht erfolgreich herunterladen. Prüfen Sie den Netzwerkstatus und wenden Sie sich dann an Ihren Systemadministrator.
1012 Das Citrix Access Gateway Plug-in konnte nicht gestartet werden. Weitere Informationen finden Sie im Verbindungsprotokoll. Das Access Gateway Plug-in konnte keine Verbindung herstellen. Prüfen Sie die Informationen im Verbindungsprotokoll und nehmen Sie die notwendigen Änderungen vor. Suchen Sie den Fehler im Verbindungsprotokoll und melden Sie den Fehler dann Ihrem Helpdesk oder Systemadministrator.
1013 Konfiguration konnte nicht geparst werden. Weitere Informationen finden Sie im Verbindungsprotokoll. Auf dem Access Gateway liegt ein Konfigurationsfehler vor. Wenden Sie sich an Ihren Helpdesk oder Systemadministrator.
1014 Das Clientgerät konnte die Access Gateway-Webadresse nicht auflösen. Das Access Gateway Plug-in konnte den Domänennamen nicht auflösen. Ändern Sie die HOSTS-Datei oder bitten Sie Ihren Systemadministrator, die Konfiguration zu ändern.
1015 Die gesicherte SSL-Verbindung konnte nicht eingerichtet werden. Das Access Gateway Plug-in konnte keine gesicherte Verbindung einrichten. Wenden Sie sich an Ihren Helpdesk oder Systemadministrator.
1016 Downgrade des Citrix Access Gateway Plug-ins von <Versionsnummer> auf <Versionsnummer> ist fehlgeschlagen. Die Installation einer früheren Version des Access Gateway Plug-ins ist fehlgeschlagen. Wenden Sie sich an Ihren Helpdesk oder Systemadministrator.
1016 Upgrade des Citrix Access Gateway Plug-ins von <Versionsnummer> auf <Versionsnummer> ist fehlgeschlagen. Das Access Gateway Plug-in konnte nicht auf die neueste Version aktualisiert werden. Wenden Sie sich an Ihren Helpdesk oder Systemadministrator.
2001 Die Access Gateway-Sitzung hat das Zeitlimit überschritten und Sie sind nicht verbunden. Diese Meldung gibt an, dass Access Gateway-Sitzung das Zeitlimit überschritten hat. Melden Sie sich am Access Gateway Plug-in ab und melden Sie sich neu an.
2003 Auf dem Access Gateway liegt ein Konfigurationsproblem vor. Diese Meldung gibt an, dass die Konfiguration auf dem Access Gateway falsch ist. Wenden Sie sich an Ihren Systemadministrator, um Access Gateway richtig zu konfigurieren.
2004 Sie müssen die Endpunktsicherheitssoftware installieren. Diese Meldung gibt an, dass mindestens eine der erforderlichen Endpunktsicherheitsanwendungen nicht installiert ist. Wenden Sie sich an Ihren Systemadministrator, um die erforderliche Sicherheitssoftware zu installieren.
2005 Sie müssen die Endpunktsicherheitssoftware aktualisieren. Diese Meldung gibt an, dass die Endpunktsicherheitssoftware nicht die richtige Version hat. Wenden Sie sich an Ihren Systemadministrator, um die Sicherheitssoftware zu aktualisieren.
2006 Die erforderliche Sicherheitssoftware ist nicht aktiviert. Diese Meldung gibt an, dass die Endpunktsicherheitssoftware nicht aktiviert ist. Starten Sie die Sicherheitssoftware.
2007 Diese Version des Access Gateway Plug-ins wurde aktualisiert. Melden Sie sich neu an. Diese Meldung gibt an, dass die Version des Access Gateway Plug-ins auf dem Benutzergerät nicht mit der auf dem Access Gateway übereinstimmt. Melden Sie sich ab und melden Sie sich neu an.
2008 Die Versionen von Access Gateway Plug-in und Access Gateway stimmen nicht überein. Melden Sie sich über den Webbrowser an, um das Upgrade durchzuführen. Die Version des Access Gateway Plug-ins stimmt nicht mit der Access Gateway-Version überein. Benutzer können ein automatisches Upgrade ausführen, indem sie sich am Webbrowser anmelden. Deinstallieren Sie das Access Gateway Plug-in, starten Sie das Benutzergerät neu und melden Sie sich dann neu an, um das Plug-in zu installieren.
2008 Diese Version des Access Gateway Plug-ins wurde aktualisiert. Melden Sie sich neu an. Das Upgrade des Access Gateway Plug-ins ist erfolgreich, es wurde jedoch nicht automatisch aktiviert. Melden Sie sich ab und melden Sie sich neu an.
2009 Der Proxyserver erfordert eine nicht unterstützte Authentifizierung. Für die Einstellung eines lokalen Weiterleitungsproxys ist eine Authentifizierung erforderlich. Nicht alle Proxy-unterstützten Authentifizierungstypen werden vom Access Gateway Plug-in unterstützt. Keine
2010 Proxyserverauthentifizierung fehlgeschlagen, bitte melden Sie sich neu an. Für die Einstellung eines lokalen Weiterleitungsproxys ist eine Authentifizierung erforderlich. Diese Fehlermeldung wird angezeigt, wenn der Benutzer keinen gültigen Benutzernamen oder kein gültiges Kennwort angegeben hat. Keine
2011 Das Access Gateway konnte das Sicherheitszertifikat nicht validieren. Das Clientzertifikat ist nicht das richtige Zertifikat. Das Zertifikat kann in einem Webbrowser oder auf einer Smartcard gespeichert werden. Das Access Gateway Plug-in kann das erforderliche Zertifikat nicht erkennen. Wenden Sie sich an Ihren Helpdesk oder Systemadministrator, um das richtige Clientzertifikat bereitzustellen.
2012 Das Citrix Access Gateway Plug-in wurde nicht gestartet. Das Citrix Access Gateway Plug-in wurde nicht gestartet. Hierzu muss der Benutzer als Administrator angemeldet sein. Melden Sie sich mit dem Access Gateway Plug-in mit einem Administratorkonto an.
2013 Die Proxyeinstellungen im Webbrowser konnten nicht gelesen werden. Das Access Gateway Plug-in hat die Proxyeinstellungen im Browser nicht gelesen. Keine
2014 Das Access Gateway Plug-in unterstützt diese Version des Betriebssystems nicht. Weitere Informationen erhalten Sie von Ihrem Helpdesk oder Systemadministrator. Der Benutzer versucht, das Access Gateway Plug-in unter einer nicht unterstützten Version des Betriebssystems zu installieren. Keine
2014 Sie müssen die Anwendung <Anwendungsname> beenden. Das Access Gateway ist so konfiguriert, dass das Ausführen der festgelegten Anwendung auf dem Benutzergerät verhindert wird. Beenden Sie die Anwendung.
2015 Diese Anmeldung überschreitet die maximale Anzahl zulässiger Benutzer. Alle Lizenzen auf dem Access Gateway werden verwendet. Wenden Sie sich an Ihren Helpdesk oder Systemadministrator.
2016 Das Access Gateway ist nicht verfügbar. Die Verbindung zu Access Gateway kann nicht hergestellt werden. Keine
2017 Konfigurierte benutzerdefinierte Fehlermeldung. Diese Fehlermeldung wurde von Ihrem Systemadministrator konfiguriert und darf nicht mehr als 100 Zeichen enthalten. Diese Fehlermeldung wird angezeigt, wenn die Endpunktanalyse fehlschlägt. Wenden Sie sich an Ihren Helpdesk oder Systemadministrator.
2017 Auf dem Computer ist nicht die für die Verbindung mit dem Access Gateway erforderliche Sicherheitssoftware installiert. Wenden Sie sich an Ihren Helpdesk bzw. Systemadministrator. Falls die Benutzergerätsicherheitsprüfung fehlschlägt und der Systemadministrator nicht die benutzerdefinierte Fehlermeldung verwendet, wird diese Standardfehlermeldung angezeigt. Wenden Sie sich an Ihren Helpdesk oder Systemadministrator.
2018 Das Access Gateway hat keine Tastatur- oder Mausaktivität festgestellt. Die Sitzung hat das Zeitlimit überschritten. Das Zeitlimit der Sitzung wurde überschritten, weil innerhalb einer angegebenen Zeitspanne keine Aktivität auf dem Benutzergerät festgestellt wurde. Melden Sie sich ab und melden Sie sich neu an.
2019 Die Verbindung zum Access Gateway kann nicht hergestellt werden, weil die Endpunktanalyse fehlgeschlagen ist. Access Gateway erfordert bestimmte Software, Prozesse oder Dateien auf dem Benutzergerät Wenn das Benutzergerät die Anforderungen der Endpunktanalyse nicht erfüllt, können Benutzer sich nicht anmelden. Beenden Sie das Access Gateway Plug-in und konfigurieren Sie das Benutzergerät mit den richtigen Einstellungen, um die Endpunktanalyse zu bestehen.
2020 Das Webinterface wird für Benutzerverbindungen verwendet. Verwenden Sie Internet Explorer für die Anmeldung. Das Webinterface wird nur von Internet Explorer unterstützt. Verwenden Sie Internet Explorer für die Herstellung einer Verbindung mit der Webinterface.
3001 Sie sind bereits am Access Gateway angemeldet. Sie sind am Access Gateway mit dem Access Gateway Plug-in angemeldet. Keine
3002 Sie sind nicht am Access Gateway angemeldet. Das Access Gateway-Sitzungscookie kann nicht gefunden werden. Prüfen Sie, ob der Benutzer angemeldet ist. Melden Sie sich mit dem Access Gateway Plug-in an.
3003 Das Access Gateway unterstützt Internet Explorer 4 und höher. Diese Meldung gibt an, dass das Access Gateway keine Installation von Internet Explorer auf dem Benutzergerät erkennen kann. Es könnte auch bedeuten, dass auf dem Benutzergerät eine ältere, nicht unterstützte Version von Internet Explorer installiert ist. Falls Sie Windows Vista verwenden, ist Internet Explorer 7 die einzige unterstützte Version für dieses Betriebssystem. Aktualisieren Sie Internet Explorer und melden Sie sich neu an.
3006 Das Endpoint Analysis Plug-in konnte nicht gestartet werden. Wenden Sie sich an Ihren Helpdesk oder Systemadministrator. Das Plug-in konnte nicht gestartet werden. Wenden Sie sich an Ihren Helpdesk oder Systemadministrator.
