Melden von Fehlern mit dem Access Gateway Plug-in

Sie können das Access Gateway Plug-in konfigurieren, um alle Fehler in einer Textdatei zu protokollieren. Das Access Gateway Plug-in protokolliert alle wichtigen Aktivitäten in einer Protokolldatei. Diese Dateien werden auf Ihrem Gerät gespeichert. Sie können diese Dateien an Ihren Helpdesk oder Systemadministrator senden.

Unter Windows XP werden die Protokolldateien in den Verzeichnissen %systemdrive%\Dokumente und Einstellungen\All Users\Anwendungsdaten\Citrix\AGEE und %systemdrive%\Dokumente und Einstellungen\%username%\Lokale Einstellungen\Anwendungsdaten\Citrix\AGEE gespeichert.

Unter Windows Vista und Windows 7 werden die Protokolldateien in den Verzeichnissen %systemdrive%\ProgramData\Citrix\AGEE und %systemdrive%\Benutzer\%username%\AppData\Lokal\Citrix\AGEE gespeichert. Ihr Systemadministrator kann diese Protokolldateien bei der Behandlung von Problemen mit dem Access Gateway Plug-in verwenden.

Sie können die Protokollstufe für das Access Gateway Plug-in einstellen. Es gibt die folgenden Protokollstufen:

  • Debuggingmeldungen nicht aufzeichnen
  • Ereignismeldungen aufzeichnen
  • Nur Access Gateway Plug-in-Statistiken aufzeichnen
  • Alle Fehler, Ereignismeldungen und Statistiken aufzeichnen
  1. Klicken Sie im Infobereich mit der rechten Maustaste auf das Access Gateway Plug-in-Symbol und klicken Sie dann auf Access Gateway konfigurieren.
  2. Klicken Sie auf die Registerkarte Tracing, wählen Sie die Protokollstufe aus und klicken Sie auf OK.

Anzeigen von Protokolldateien

Die Protokolldateien enthalten Informationen über Probleme, die unter Umständen beim Ausführen des Access Gateway Plug-ins auftreten. Diese Informationen sind nützlich, wenn ein Problem auftritt und Sie gemeinsam mit dem technischen Support arbeiten.

  1. Klicken Sie im Infobereich mit der rechten Maustaste auf das Access Gateway Plug-in-Symbol und klicken Sie dann auf Access Gateway konfigurieren.
  2. Klicken Sie auf die Registerkarte Tracing.
  3. Klicken Sie unter Clienttracingprotokoll auf Protokolldatei anzeigen.
