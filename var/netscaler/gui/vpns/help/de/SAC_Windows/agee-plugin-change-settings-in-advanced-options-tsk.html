Ändern der Einstellungen im Dialogfeld "Erweiterte Optionen"

Im Dialogfeld Access Gateway Plug-in können Sie die folgenden Einstellungen ändern:

  • IP-Adresse oder Webadresse für Access Gateway
  • Proxyservereinstellungen
  • Sicherheitszertifikatswarnungen
Anmerkung: Diese Einstellungen können Sie ändern, wenn das Access Gateway Plug-in so konfiguriert wurde, dass bei der Anmeldung das Access Gateway-Dialogfeld statt eines Webbrowsers verwendet wird. Weitere Informationen finden Sie unter Erstellen von Verbindungen mit dem Access Gateway Plug-in.

Einstellen der Access Gateway-Webadresse

Wenn das Access Gateway Plug-in konfiguriert ist, stellen Sie mit der vorkonfigurierten IP-Adresse des Access Gateways eine Verbindung her. Sie können das Plug-in auch so konfigurieren, dass eine Verbindung zu einem anderen Gerät hergestellt wird.

  1. Klicken Sie im Infobereich mit der rechten Maustaste auf das Access Gateway Plug-in-Symbol und klicken Sie dann auf Anmelden.
  2. Klicken Sie im Anmeldedialogfeld Citrix Access Gateway mit der rechten Maustaste auf eine beliebige Stelle und wählen Sie dann Erweiterte Optionen.
  3. Geben Sie unter Citrix Access Gateway-Konfiguration in Webadresse die Webadresse ein und klicken Sie dann auf OK.

    Die Webadresse kann eine IP-Adresse wie 192.168.1.2 oder eine Webadresse wie https://ag1.Unternehmen.com sein.

Konfigurieren von Proxyservern für das Access Gateway Plug-in

Ein Proxyserver ist ein Computer, der sich zwischen Ihrem Gerät und Servern im internen Netzwerk befindet. Proxyserver fangen Anfragen von Ihrem Webbrowser an den Server im internen Netzwerk ab, um festzustellen, ob der Proxyserver die angefragte Webseite erfüllen kann. Wenn der Proxyserver die Anfrage nicht erfüllen kann, wird die Anfrage an den Server im gesicherten Netzwerk gesendet.

Wenn Sie den Proxyserver manuell konfigurieren, ist die automatische Erkennung der Proxyeinstellungen deaktiviert.

  1. Klicken Sie im Infobereich mit der rechten Maustaste auf das Access Gateway-Symbol und klicken Sie auf Anmelden.
  2. Klicken Sie im Citrix Access Gateway-Anmeldedialogfeld mit der rechten Maustaste auf eine beliebige Stelle und wählen Sie dann Erweiterte Optionen.
  3. Wählen Sie unter Proxyeinstellungen die Option Proxyserver manuell konfigurieren aus.
  4. Geben Sie in IP-Adresse und Port die IP-Adresse und die Portnummer ein.
Anmerkung: Um auf das Anmeldedialogfeld und die Erweiterten Optionen zum Konfigurieren der Proxyeinstellungen zuzugreifen, müssen Sie sich von Access Gateway abmelden.

Anmelden mit einem sekundären Kennwort

Bei einigen Access Gateway-Geräten müssen Sie sich unter Umständen mit zwei Authentifizierungstypen anmelden. Dies kann Ihren Benutzernamen, Ihr Kennwort und eine persönliche Identifikationsnummer (PIN) gefolgt von einer Nummer von einem Token umfassen, wie eine RSA SecurID-Tokennummer.

Bei der Standardeinstellung des Access Gateway-Dialogfelds werden die Anmeldefelder für Ihren Benutzernamen und Ihr Kennwort angezeigt. Sie können das Access Gateway Plug-in so konfigurieren, dass das Feld für das sekundäre Kennwort angezeigt wird.

  1. Klicken Sie im Infobereich mit der rechten Maustaste auf das Access Gateway-Symbol und klicken Sie dann auf Öffnen.
  2. Klicken Sie im Dialogfeld mit der rechten Maustaste auf eine beliebige Stelle und klicken Sie dann auf Sekundäres Kennwort anzeigen.
Anmerkung: Wenn das Feld für das sekundäre Kennwort nicht benötigt wird, klicken Sie im Access Gateway-Dialogfeld mit der rechten Maustaste auf eine beliebige Stelle und klicken Sie dann auf Sekundäres Kennwort ausblenden.
