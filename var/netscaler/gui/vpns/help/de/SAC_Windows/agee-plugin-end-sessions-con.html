Beenden der Access Gateway Plug-in-Sitzungen

Sie können die Sitzung mit dem Access Gateway Plug-in auf folgende Weise beenden:

  • Abmelden vom Access Gateway
  • Beenden der Sitzung

So melden Sie sich vom Access Gateway ab

Wenn Sie sich abmelden, wird die Sitzung beendet und das Access Gateway-Symbol bleibt im Infobereich.

Sie können sich auf zwei Arten vom Access Gateway abmelden:

  • Klicken Sie im Access Interface auf Abmelden.
  • Klicken Sie im Infobereich mit der rechten Maustaste auf das Access Gateway-Symbol und klicken Sie dann auf Abmelden.

So beenden Sie die Sitzung

Wenn Sie eine Sitzung beenden, wird die Sitzung geschlossen und das Access Gateway-Symbol wird aus dem Infobereich entfernt.

  • Klicken Sie im Infobereich mit der rechten Maustaste auf das Access Gateway-Symbol und klicken Sie dann auf Beenden.
