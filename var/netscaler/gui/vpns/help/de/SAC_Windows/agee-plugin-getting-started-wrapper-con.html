Erste Schritte mit dem Access Gateway Plug-in

Access Gateway ist ein Hardwaregerät, das Kommunikation zwischen Ihrem Gerät und einem remoten Unternehmensnetzwerk bereitstellt. Es erstellt eine gesicherte Verbindung zwischen Ihrem Gerät und Access Gateway. Über diese gesicherte Verbindung wir Ihnen der Zugriff auf wichtige Unternehmensressourcen wie E-Mail, freigegebene Dateisysteme und Anwendungen ermöglicht.
