Aktualisieren des Access Gateway Plug-ins

Das Access Gateway Plug-in für Windows wird automatisch aktualisiert, wenn eine neue Version der Software verfügbar ist. Wenn Sie sich am Access Gateway anmelden, erkennt es die auf Ihrem Gerät installierte Plug-in-Version. Falls die Plug-in-Version nicht mit der auf dem Access Gateway übereinstimmt, wird die Software automatisch auf Ihrem Computer aktualisiert. Nach dem Abschluss der Aktualisierung können Sie sich am Access Gateway anmelden und eine Verbindung zu Netzwerkressourcen im internen Netzwerk herstellen.

Wenn Ihr Systemadministrator das Access Gateway so konfiguriert, dass Ihr Computer nach Software, Dateien, Prozessen und anderen Objekten durchsucht wird, wird das Endpoint Analysis Plug-in automatisch installiert. Dieses Plug-in durchsucht Ihren Computer nach der erforderlichen Software. Das Endpoint Analysis Plug-in wird auch automatisch aktualisiert, wenn eine neue Version verfügbar ist.

Falls Sie eine Verbindung zu mehr als einem Access Gateway-Gerät herstellen können, unterscheiden sich unter Umständen die Softwareversionen, die auf den jeweiligen Geräten ausgeführt werden. Das Gerät ag1 hat beispielsweise eine neuere Version der Access Gateway-Software als das Gerät ag2. Falls Sie ursprünglich eine Verbindung zu ag1 herstellen, die Sitzung beenden und dann eine Verbindung zu ag2 herstellen, werden das Access Gateway Plug-in und das Endpoint Analysis Plug-in automatisch auf die Version heruntergestuft, die auf ag2 ist.
