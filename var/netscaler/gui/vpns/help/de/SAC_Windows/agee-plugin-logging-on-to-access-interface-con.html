Anmelden am Access Interface

Sie können sich mit verschiedenen Methoden an der Homepage anmelden, abhängig davon wie der Systemadministrator das Access Gateway-Gerät konfiguriert hat. Das Access Interface oder eine benutzerdefinierte Homepage, die Ihr Systemadministrator installiert hat, wird möglicherweise angezeigt. Falls Sie nach dem Anmelden eine Webadresse eingeben, sehen Sie unter Umständen eine dieser drei Optionen:

  • Citrix XenApp
  • Clientloser Zugriff
  • Netzwerkzugriff

Citrix XenApp gibt Zugriff auf Anwendungen, die im Unternehmensnetzwerk sind. Der Systemadministrator kann jeden Anwendungstyp veröffentlichen, z. B. Microsoft Word oder Outlook.

Wenn Sie Citrix XenApp ausgewählt haben, werden Sie angemeldet und eine Liste Ihrer veröffentlichten Anwendungen wird angezeigt.

Wenn Sie sich über einen clientlosen Zugriff oder mit dem Access Gateway Plug-in (indem Sie auf Netzwerkzugriff klicken) anmelden und der Administrator veröffentlichte Anwendungen auf dem Access Gateway konfiguriert hat, werden auf der Access Interface-Homepage im linken Bereich Ihre veröffentlichten Anwendungen angezeigt, wie in der folgenden Abbildung:
