Aufräumen des Computers nachdem die Sitzung beendet ist

Während einer Sitzung werden temporäre Dateien auf Ihrem Computer erstellt. Access Gateway hat eine Bereinigungsfunktion, um temporäre Dateien von Ihrem Computer zu entfernen. Der Systemadministrator aktiviert diese Funktion.

Sie können die folgenden Objekte für die Bereinigung auswählen, um diese von Ihrem Computer zu entfernen:

  • Access Gateway Plug-in
  • Zertifikate, die für die Authentifizierung verwendet werden
  • Anwendungen, die während der Sitzung verwendet werden
  • Kennwörter und Daten für die automatische Vervollständigung
  • Verlauf und Webadressen, die in die Adressleiste eingegeben wurden
  • Cookies und temporäre Dateien

Suchen von Information auf der Registerkarte "Übersicht"

Die Registerkarte Übersicht enthält folgende Informationen über Ihre Sitzung:

  • Gesamtanzahl der geänderten Registrierungseinträge
  • Gesamtanzahl der installierten Cookies
  • Gesamtanzahl der verwendeten Anwendungen

Konfigurieren der Bereinigungsstufe

Sie können Access Gateway so konfigurieren, dass einige oder alle Datensätze gelöscht werden, wenn Sie sich abmelden. Unter Umständen möchten Sie einige der Daten behalten, z. B. Daten für die automatische Vervollständigung, gespeicherte Kennwörter und den Verlauf, besonders dann, wenn es Ihr eigener Computer ist. Daten werden in die folgenden drei Gruppen unterteilt, um Sie beim gezielten Löschen von Daten zu unterstützen:

Keine: Wenn diese Stufe ausgewählt ist, werden die Datensätze nicht gelöscht.

Nur Webbrowser: Wenn diese Stufe ausgewählt ist, können Sie das Access Gateway so einstellen, dass einer oder mehrere der folgenden Datensätze gelöscht werden:

  • Kennwörter und Daten für die automatische Vervollständigung, die vom Browser gespeichert werden
  • Verlauf und Webadressen, die in die Adressleiste eingegeben wurden
  • Cookies im Browsercache und temporäre Dateien

Alle Elemente: Wenn diese Stufe ausgewählt ist, können Sie das Access Gateway so einstellen, dass alle temporären Daten, die von dem Computer generiert wurden, gelöscht werden.

Konfigurieren des Bereinigungsvorgangs

Der Systemadministrator steuert den Bereinigungsvorgang. Das Dialogfeld für die Bereinigung wird nur angezeigt, wenn der Administrator Access Gateway so konfiguriert, dass dieses Dialogfeld angezeigt wird. Zusätzlich kann der Administrator Access Gateway auch so konfigurieren, dass bestimmte Datensätze von Ihrem Computer gelöscht werden, wenn Sie die Sitzung beenden. Die Optionen, die diesen Datensätzen entsprechen, werden auf der Registerkarte Liste des Dialogfelds Citrix Windows-Bereinigung deaktiviert. Die verbleibenden Optionen sind anhand der von Ihnen ausgewählten Bereinigungsstufe aktiviert oder deaktiviert.

  1. Klicken Sie im Dialogfeld Citrix Windows-Bereinigung auf Liste.
  2. Aktivieren oder deaktivieren Sie das Kontrollkästchen neben dem Datensatz.

Anzeigen der Bereinigungsprotokolle

Das Access Gateway Plug-in protokolliert die gesamte Bereinigungsaktivität in einer Datei, die auf Ihrer Festplatte gespeichert wird. In dieser Liste werden die Aktion, die ausgeführt wurde, und die Dateien, die gelöscht wurden, aufgelistet.

  1. Klicken Sie auf der Registerkarte Übersicht auf Protokoll anzeigen.
