Arbeiten mit dem Access Interface

Access Gateway hat das Access Interface, das der in der folgenden Abbildung dargestellten Homepage entspricht. In diesem Abschnitt werden die internen Websites und Dateifreigaben für Ihr Unternehmen angezeigt, auf die am häufigsten zugegriffen wird. Der Administrator konfiguriert die Links, die unter Unternehmenswebsites oder Unternehmensfreigaben angezeigt werden. Sie können Ihre eigenen Lesezeichen erstellen. Sie werden unter Persönliche Websites oder Persönliche Dateifreigaben angezeigt. In diesem Abschnitt werden die Konfigurationsaufgaben erklärt, die Sie im Access Interface durchführen können.
