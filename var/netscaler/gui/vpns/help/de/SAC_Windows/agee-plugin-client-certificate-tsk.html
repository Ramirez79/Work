Anmelden mit einem Clientzertifikat

Unter Umständen melden Sie sich am Access Gateway mit einem Clientzertifikat an. Bei Anmelden am Access Gateway werden Ihre Details im Zertifikat mit Informationen verglichen, die der Systemadministrator auf dem Access Gateway konfiguriert hat. Wenn die Details übereinstimmen, können Sie sich anmelden. Wenn die Details nicht übereinstimmen, wird die Anmeldung möglicherweise verweigert.

Access Gateway kann ein Clientzertifikat authentifizieren, das an einem dieser Orte gespeichert ist:

  • Im Zertifikatspeicher des Windows-Betriebssystems auf Ihrem Gerät. In diesem Fall wird das Clientzertifikat separat im Zertifikatspeicher mit der Microsoft Management Console installiert.
  • Auf einer Smartcard oder einem Hardwaretoken. In diesem Fall wird das Zertifikat auf der Smartcard eingebettet und von einem mit dem Netzwerk verbundenen Smartcardleser gelesen.
  • Auf einer Zugriffskarte, die das United States Department of Defense für die Identifizierung und Authentifizierung verwendet.

Um das Clientzertifikat auf Ihrem Gerät zu installieren, folgen Sie den Anweisungen, die Ihnen der Systemadministrator oder das Helpdesk-Personal zur Verfügung gestellt haben.

Wenn Sie mehrere Clientzertifikate auf Ihrem Gerät installiert haben, werden Sie vom Access Gateway Plug-in aufgefordert, das richtige Zertifikat für die Anmeldung auszuwählen.

Wenn Sie Internet Explorer oder das Dialogfeld Access Gateway Plug-in für die Anmeldung verwenden, wird das Clientzertifikat aus dem Windows-Zertifikatspeicher verwendet. Wenn Sie den Firefox-Webbrowser für die Anmeldung verwenden, müssen Sie das Zertifikat in Firefox importieren.

So importieren Sie ein Clientzertifikat in Firefox

  1. Öffnen Sie den Firefox-Webbrowser.
  2. Klicken Sie im Menü auf Extras und dann auf Einstellungen.
  3. Klicken Sie auf Erweitert.
  4. Klicken Sie im Dialogfeld Zertifikate auf Zertifikate anzeigen. Klicken Sie dann auf Importieren.
  5. Navigieren Sie zu dem auf Ihrem Computer gespeicherten Zertifikat und klicken Sie dann auf Öffnen.

    Sie werden eventuell nach einem Kennwort für das Zertifikat gefragt. Wenden Sie sich für das Kennwort an Ihren Systemadministrator oder das Helpdesk-Personal.

  6. Klicken Sie auf OK.

Weitere Informationen zum Importieren von Zertifikaten in Firefox finden Sie in der Firefox-Hilfe.
