Systemanforderungen für das Access Gateway Plug-in

Das Access Gateway Plug-in wird auf den folgenden Betriebssystemen ausgeführt:

  • Windows XP (32 Bit)
  • Windows Vista (32 Bit und 64 Bit)
  • Windows 7 (32 Bit und 64 Bit)

Die folgenden Webbrowser werden unterstützt:

  • Internet Explorer
  • Firefox
