Erstellen von Verbindungen mit dem Access Gateway Plug-in

Damit Sie eine Verbindung mit dem Access Gateway Plug-in herstellen und es verwenden können, muss der Systemadministrator Ihnen die folgenden Informationen geben:

  • Access Gateway-Webadresse, z. B. https://AccessGatewayFQDN/.
  • Alle vom Systemadministrator festgelegten Systemanforderungen zum Ausführen des Plug-ins. Systemanforderungen können eine auf Ihrem Computer installierte Antivirussoftware oder persönliche Firewall umfassen.

Abhängig von der Konfiguration des Computers müssen Sie eventuell weitere Anforderungen erfüllen:

  • Um das Access Gateway Plug-in zu installieren, müssen Sie ein lokaler Administrator oder ein Mitglied der Gruppe "Administratoren" sein, um Programme auf Ihrem Computer zu installieren.
  • Falls Sie auf Ihrem Computer eine persönliche Firewall verwenden, werden Sie bei der ersten Verbindung mit dem Plug-in eventuell von der Firewall aufgefordert, die Verbindung zuzulassen. Falls Ihnen diese Aufforderung angezeigt wird, lassen Sie die Verbindung immer zu. Informationen über das Zulassen von Verbindungen finden Sie in der Dokumentation des Herstellers.

Herstellen einer Verbindung mit einer Webadresse

Wenn Sie eine Verbindung mit einer Webadresse herstellen, werden Sie entweder zur Anmeldung aufgefordert oder direkt zu einer Portalseite weitergeleitet, auf der Sie eine Verbindung mit dem Access Gateway Plug-in herstellen.

Wenn Access Gateway so konfiguriert ist, das Sie sich anmelden müssen, bevor Sie eine Verbindung mit dem Plug-in herstellen können, geben Sie Ihren Benutzernamen und Ihr Kennwort ein und melden Sie sich an. Auf der angezeigten Webseite können Sie das Plug-in herunterladen und installieren. Nachdem das Access Gateway Plug-in installiert ist, bietet die Verbindung vollständigen Zugriff auf die Netzwerkressourcen, die Sie verwenden dürfen.

Herunterladen und Installieren des Access Gateway Plug-ins

Wenn Sie zum ersten Mal eine gesicherte Verbindung herstellen, melden Sie sich am Access Gateway mit einem Webbrowser an. Wenden Sie sich für die Webadresse und die Anmeldeinformationen an den Administrator. Das typische Format einer Webadresse ist https://ag.Unternehmensname.com.

  1. Geben Sie in einem Webbrowser die Webadresse des Access Gateways ein.
  2. Geben Sie Ihren Benutzernamen und Ihr Kennwort ein und klicken Sie auf Anmelden.
  3. Klicken Sie auf Netzwerkzugriff, um das Plug-in zu installieren.

Nach Abschluss des Downloads stellt das Plug-in eine Verbindung her und zeigt im Infobereich der Taskleiste eine Meldung an. Sie können sich auch mit dem Access Gateway-Symbol im Infobereich anmelden.

Verbinden über das Dialogfeld "Access Gateway Plug-in"

Wenn Sie mit dem Access Gateway Plug-in eine Verbindung ohne einen Webbrowser herstellen möchten, können Sie das Plug-in zur Anzeige des Anmeldedialogfelds konfigurieren, wenn Sie auf das Symbol im Infobereich klicken.

Anmerkung: Zum Konfigurieren der Einstellungen des Access Gateway Plug-ins müssen Sie angemeldet sein.
  1. Klicken Sie im Infobereich mit der rechten Maustaste auf das Access Gateway-Symbol und klicken Sie dann auf Access Gateway konfigurieren.
  2. Klicken Sie auf die Registerkarte Profil und dann auf Profil ändern.
  3. Klicken Sie auf der Registerkarte Optionen auf Access Gateway Plug-in für Anmeldung verwenden.

Sie können sich anmelden, indem Sie auf dem Desktop auf das Access-Gateway-Symbol doppelklicken oder im Infobereich der Taskleiste mit der rechten Maustaste auf das Access Gateway-Symbol klicken und dann auf Anmelden klicken. Weitere Informationen zum Konfigurieren des Access Gateway Plug-ins finden Sie unter Ändern der Einstellungen im Dialogfeld "Erweiterte Optionen".
