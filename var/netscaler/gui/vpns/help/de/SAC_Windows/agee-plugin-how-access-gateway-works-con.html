Funktionsweise von Access Gateway

Um sich an Ihrem internen Unternehmensnetzwerk anzumelden, müssen Sie sich am Access Gateway anmelden. Hierbei verwenden Sie das Access Gateway Plug-in. Installieren Sie beim Anmelden am internen Netzwerk das Plug-in auf Ihrem Computer und melden Sie sich dann an.

Das Access Gateway Plug-in wird auf Ihrem Computer installiert, wenn Sie sich das erste Mal anmelden. Nachdem das Plug-in installiert ist, können Sie sich über das Symbol auf Ihrem Desktop anmelden oder eine Verbindung über eine Webportalseite herstellen.

Wenn das Access Gateway Plug-in auf Ihren Computer heruntergeladen und eine Verbindung hergestellt wird, erstellt Access Gateway einen gesicherten Kommunikationskanal zwischen Ihrem Computer und Access Gateway und ermöglicht Ihnen, auf Ressourcen im internen Netzwerk zugreifen, für die Sie Zugriffsberechtigung haben.

Der Systemadministrator kann das Access Gateway Plug-in auch konfigurieren, um sicherzustellen, dass bestimmte persönliche Firewall- und Antivirus-Anwendungen auf Ihrem Computer ausgeführt werden.
