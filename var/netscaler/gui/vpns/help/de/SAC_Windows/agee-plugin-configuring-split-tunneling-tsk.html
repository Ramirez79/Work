Konfigurieren von Split-Tunneling

Wenn Split-Tunneling aktiviert ist, filtert Access Gateway den Verkehr mit der IP-Adresse des Zielnetzwerks. Verkehr, der für das Unternehmensnetzwerk bestimmt ist, wird durch Access Gateway gesendet und der restliche Verkehr wird zum lokalen Netzwerk (LAN) oder zum Internet gesendet. Split-Tunneling beschränkt den Netzwerkverkehr durch Access Gateway basierend auf der IP-Adresse.

Wenn Sie beispielsweise eine Verbindung zu einer Intranetwebsite im Netzwerk der Organisation herstellen, geht die Anfrage an Access Gateway. Wenn Sie eine Verbindung zu einer externen Website herstellen, z. B. cnn.com, wird der Netzwerkverkehr nicht durch das Access Gateway geleitet.

Split-Tunneling hat drei Optionen:

  • Ein: Wenn Split-Tunneling aktiviert ist, vergleicht das Access Gateway Plug-in die IP-Adresse und den Port des Ziels mit den Werten, die vom Systemadministrator auf dem Access Gateway konfiguriert wurden. Falls einer der Werte übereinstimmt, werden die Pakete durch das Access Gateway zum Remotenetzwerk gesendet. Wenn nicht, werden die Pakete an das LAN umgeleitet.
  • Aus: Wenn Sie die Option Aus wählen, wird Split-Tunneling deaktiviert und das Access Gateway Plug-in sendet den gesamten Verkehr durch das Access Gateway zum Remotenetzwerk.
  • Umkehren: Wenn Umkehren aktiviert ist, werden Internetverbindungen und Anfragen an Ihr LAN durch das Access Gateway gesendet. Verbindungen zu internen Netzwerkressourcen werden nicht durch das Access Gateway geleitet. Diese Einstellung wird normalerweise verwendet, wenn das Access Gateway im internen Netzwerk ist und Sie eine Verbindung von Ihrem Büro aus herstellen.
Wichtig: Falls Split-Tunneling auf dem Access Gateway deaktiviert ist, werden die entsprechenden Steuerelemente für Split-Tunneling und Split-DNS im Access Gateway Plug-in deaktiviert und Sie können diese Einstellungen nicht ändern. Der gesamte Netzwerkverkehr wird durch das Access Gateway gesendet.
  1. Klicken Sie im Infobereich mit der rechten Maustaste auf das Access Gateway Plug-in-Symbol und klicken Sie dann auf Access Gateway konfigurieren.
  2. Klicken Sie auf die Registerkarte Profil und dann auf Profil ändern.
  3. Wählen Sie auf der Registerkarte Verbindungen unter Split-Tunneling die gewünschte Option aus und klicken Sie dann auf OK.
