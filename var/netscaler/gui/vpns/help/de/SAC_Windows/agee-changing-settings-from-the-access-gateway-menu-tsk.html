Ändern der Einstellungen über das Access Gateway-Menü

Wenn Sie angemeldet sind, können Sie Einstellungen über das Access Gateway-Symbol im Infobereich ändern, indem Sie mit der rechten Maustaste auf das Symbol klicken und dann im Access Gateway-Menü ein Element auswählen. In diesem Menü können Sie Folgendes durchführen:

  • Öffnen des Access Interface oder der Homepage, die vom Systemadministrator konfiguriert wurde
  • Starten der Dateiübertragungsanwendung
  • Ändern der Konfigurationseinstellungen
  • Öffnen des Verbindungsprotokolls
  • Anzeigen der aktuellen Access Gateway Plug-Meldung
  • Öffnen der Onlinehilfe
  • Abmelden und Beenden des Access Gateway Plug-ins

Der Administrator kann das Access Gateway Plug-in so konfigurieren, dass Sie keinen Zugriff auf das Access Interface, die Dateiübertragungsanwendung oder die Konfigurationseinstellungen haben. Wenn der Administrator das Access Gateway Plug-in so konfiguriert hat, werden diese Elemente im Menü nicht angezeigt.

Öffnen des Access Interface

Mit dem von Citrix bereitgestellten Access Interface können Sie Verbindungen zu anderen Computern testen, Lesezeichen konfigurieren, Dateien übertragen und eine Verbindung zu webbasierten E-Mails wie Outlook Web Access herstellen. Weitere Informationen zur Homepage finden Sie unter Arbeiten mit dem Access Interface.

Der Systemadministrator deaktiviert das Access Interface unter Umständen und verwendet eine andere Webseite als Ihre Homepage. In diesem Abschnitt wird das Arbeiten mit dem Access Interface beschrieben.

  1. Klicken Sie im Infobereich mit der rechten Maustaste auf das Access Gateway-Symbol und klicken Sie dann auf Home.

Anzeigen und Ändern der Access Gateway Plug-in-Informationen und -Einstellungen

Mit dem Menü, das über das Access Gateway-Symbol im Infobereich verfügbar ist, können Sie das Dialogfeld Citrix Access Gateway-Konfiguration öffnen. Sie können Informationen über die Access Gateway-Verbindung anzeigen und Einstellungen für die Verbindungen konfigurieren.

Anmerkung: Zum Öffnen des Dialogfelds müssen Sie angemeldet sein.
  1. Klicken Sie mit der rechten Maustaste auf das Access Gateway-Symbol im Infobereich und klicken Sie dann auf Access Gateway konfigurieren.

Anzeigen der Verbindungsstatistiken

Im Konfigurationsdialogfeld können Sie die folgenden Informationen anzeigen:

  • Anzeigen der Verbindungsstatistiken
  • Anzeigen Ihres Profils, z. B. das Access Gateway-Gerät, mit dem Sie verbunden sind, die Netzwerke, zu denen Sie Verbindungen herstellen können, und weitere Konfigurationseinstellungen
  • Konfigurieren von Protokollierungsinformationen für die Access Gateway-Verbindung
  • Anzeigen von Informationen zur Verbindungskomprimierung

Auf der Registerkarte Allgemein werden Informationen über die Verbindung angezeigt. Diese Informationen sind hilfreich für das Personal des technischen Supports, wenn Sie Probleme mit der Verbindung haben.

Anmerkung: Der Administrator hat Access Gateway möglicherweise so konfiguriert, dass der Zugriff auf die Verbindungsstatistiken verhindert wird.
  1. Klicken Sie im Infobereich mit der rechten Maustaste auf das Access Gateway-Symbol und klicken Sie dann auf Access Gateway konfigurieren.
  2. Klicken Sie auf die Registerkarte Allgemein.

Ändern der Einstellungen auf der Registerkarte "Profil"

Im Konfigurationsdialogfeld auf der Registerkarte Profil können Sie die folgenden Verbindungseinstellungen ändern:

  • Split-Tunneling, Split-DNS und LAN-Zugriff
  • Domänen- und IP-Adresseinstellungen, um Verbindungen zu bestimmten Ressourcen im internen Netzwerk herzustellen
  • Netzwerke, um den Zugriff zu aktivieren oder zu deaktivieren
  • Computereinstellungen, um sich jedes Mal mit dem Access Gateway Plug-in anzumelden, ohne einen Webbrowser zu verwenden
  • Sicherheitszertifikatswarnungen
