Access Gateway Plug-inのアップグレード

Access Gateway Plug-in for Windowsは、新しいバージョンが使用できるようになると自動的にアップグレードされます。 Access Gatewayにログオンすると、デバイス上のプラグインのバージョンが検出されます。 プラグインのバージョンがAccess Gateway上にあるバージョンと一致しない場合は、コンピューター上のソフトウェアが自動的にアップグレードされます。 アップグレードが完了すると、Access Gatewayにログオンして内部ネットワークのネットワークリソースに接続できます。

システム管理者がコンピューター上のソフトウェア、ファイル、プロセス、およびそのほかの項目をスキャンするようにAccess Gatewayを構成した場合は、Endpoint Analysis Plug-inが自動的にインストールされ、必要なソフトウェアがスキャンされます。 Endpoint Analysis Plug-inも、新しいバージョンが使用できるようになると自動的にアップグレードされます。

複数のAccess Gatewayアプライアンスに接続する可能性がある場合は、各アプライアンス上で動作するソフトウェアのバージョンが異なる可能性があります。 たとえば、ag1アプライアンスがag2アプライアンスより新しいバージョンのAccess Gatewayソフトウェアを搭載しているとします。 初めにag1に接続してセッションを終了してからag2に接続すると、Access Gateway Plug-inとEndpoint Analysis Plug-inがag2上のバージョンに自動的にダウングレードされます。
