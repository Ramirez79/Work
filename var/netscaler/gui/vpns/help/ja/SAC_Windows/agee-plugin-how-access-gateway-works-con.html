Access Gatewayのしくみ

企業の内部ネットワークにログオンするには、Access Gatewayにログオンする必要があります。 ログオンにはAccess Gateway Plug-inを使用します。 内部ネットワークにログオンする場合は、コンピューターにプラグインをインストールしてログオンします。

初回ログオン時にAccess Gateway Plug-inがコンピューターにインストールされます。 プラグインをインストールすると、デスクトップ上のアイコンを使用してログオンしたり、Webポータルページを使用して接続したりできるようになります。

Access Gateway Plug-inをコンピューターにダウンロードして接続すると、コンピューターとAccess Gatewayの間にセキュリティで保護された通信チャネルが確立され、ユーザーが使用する権限を持つ内部ネットワーク内のリソースにアクセスできます。

システム管理者は、ユーザーのコンピューターで特定のパーソナルファイアウォールとアンチウイルスアプリケーションが動作していることを保証するようにAccess Gateway Plug-inを構成することもできます。
