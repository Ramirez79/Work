アクセスインターフェイスへのログオン

システム管理者によるAccess Gatewayアプライアンスの構成に応じて、いくつかの異なる方法でホームページにログオンできます。 アクセスインターフェイスかシステム管理者がインストールしたカスタムのホームページが開きます。 ログオン後にWebアドレスを入力する場合は、次の3つのオプションが表示される可能性があります。

  • Citrix XenApp
  • クライアントレスアクセス
  • ネットワークアクセス

Citrix XenAppにより、組織のネットワーク内にあるアプリケーションへのアクセスが提供されます。 システム管理者はMicrosoft WordやOutlookなど、任意の種類のアプリケーションを公開することができます。

Citrix XenAppを選択した場合は、ログオンすると公開アプリケーションの一覧が表示されます。

クライアントレスアクセスまたは（［ネットワークアクセス］をクリックして）Access Gateway Plug-inでログオンし、システム管理者がAccess Gateway上に公開アプリケーションを構成していた場合は、アクセスインターフェイスのホームページが開き、次の図のように左ペインに公開アプリケーションが表示されます。
