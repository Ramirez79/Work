セッション完了時のコンピューターのクリーンアップ

セッションの実行中、コンピューターに一時ファイルが作成されます。 Access Gatewayにはクリーンアップ機能があり、一時ファイルをコンピューターから削除できます。 システム管理者がこの機能を有効にします。

次の項目を選択してコンピューターから削除できます。

  • Access Gateway Plug-in
  • 認証に使用した証明書
  • セッション中に使用したアプリケーション
  • パスワードおよびオートコンプリートのデータ
  • 履歴およびアドレスバーに入力したWebアドレス
  • Cookieおよび一時ファイル

［概要］タブで確認できる情報

［概要］タブにはセッションについて次の情報が表示されます。

  • 変更されたレジストリエントリ数の合計
  • インストールされたCookie数の合計
  • 使用されたアプリケーション数の合計

クリーンアップレベルの構成

ログオフ時にデータセットの一部またはすべてを削除するように、Access Gatewayを構成できます。 使用するコンピューターが個人のものである場合は特に、オートコンプリートのデータ、格納したパスワード、および履歴など、一部のデータは保持するとよいでしょう。 データは次の3つのグループに分類されているので、選択してデータを削除できます。

なし： このレベルを選択すると、データセットは削除されません。

Webブラウザーのみ： このレベルを選択すると、次のデータセットを1つまたはそれ以上削除するように設定されます。

  • Webブラウザーにより格納されたパスワードおよびオートコンプリートのデータ
  • 履歴およびアドレスバーに入力したWebアドレス
  • WebブラウザーキャッシュのCookieおよび一時ファイル

すべての項目： このレベルを選択すると、コンピューターに生成されたすべての一時データを削除するように設定されます。

クリーンアッププロセスの構成

システム管理者がクリーンアッププロセスを制御します。 管理者がクリーンアップのダイアログボックスを開くようにAccess Gatewayを構成した場合にのみ、ダイアログボックスが開きます。 さらに管理者は、セッションの終了時にコンピューターから特定のデータセットを削除するように、Access Gatewayを構成することもできます。 これらのデータセットに対応するオプションは、［Citrix Windowsクリーンアップ］ダイアログボックスの［一覧］タブで選択できないようになっています。 残りのオプションは、選択したクリーンアップレベルに基づいて有効または無効になります。

  1. ［Citrix Windowsクリーンアップ］ダイアログボックスの［一覧］タブをクリックします。
  2. データセットのチェックボックスをオンまたはオフにします。

クリーンアップログの表示

Access Gateway Plug-inでは、ハードドライブ上に格納されたログファイルにすべてのクリーンアップ状況が記録されます。 このファイルには、実行された操作と削除されたファイルが記録されます。

  1. ［概要］タブで［ログを表示］をクリックします。
