Access Gateway Plug-inで発生したエラーの報告

すべてのエラーをテキストファイルに記録するようにAccess Gateway Plug-inを構成できます。 Access Gateway Plug-inにより主要な動作状況がすべてログに記録されます。 ログファイルはデバイスに格納されます。 ログファイルはヘルプデスクまたはシステム管理者に送ることができます。

Windows XPの場合は、ログファイルは%systemdrive%\Documents and Settings\All Users\Application Data\Citrix\AGEEおよび%systemdrive%\Documents and Settings\%username%\Local Settings\Application Data\Citrix\AGEEにあります。

Windows VistaおよびWindows 7の場合は、ログファイルは%systemdrive%\ProgramData\Citrix\AGEEおよび%systemdrive%\Users\%username%\AppData\Local\Citrix\AGEEにあります。 システム管理者は、これらのログファイルを使用してAccess Gateway Plug-inのトラブルシューティングをすることができます。

Access Gateway Plug-inのログレベルを設定できます。 ログレベルは次のとおりです。

  • デバッグメッセージを記録しない
  • イベントレベルメッセージを記録する
  • クライアント統計のみを記録する
  • 詳細なデバッグメッセージを記録する
  1. 通知領域のAccess Gatewayアイコンを右クリックして、［Access Gatewayを設定］を選択します。
  2. ［トレース］タブをクリックし、ログレベルを選択して［OK］をクリックします。

ログファイルの表示

ログファイルにはAccess Gateway Plug-inで発生した可能性のある問題の情報が含まれます。 実際に問題が発生してテクニカルサポート担当者と作業するときに、この情報が役立ちます。

  1. 通知領域のAccess Gatewayアイコンを右クリックして、［Access Gatewayを設定］を選択します。
  2. ［トレース］タブをクリックします。
  3. ［クライアントトレースログ］の［ログファイルを表示］をクリックします。
