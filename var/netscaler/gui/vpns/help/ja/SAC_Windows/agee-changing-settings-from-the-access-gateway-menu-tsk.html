Access Gatewayメニューを使用した設定変更

ログオンした後は、通知領域のAccess Gatewayアイコンを右クリックすると表示されるAccess Gatewayメニューから項目を選択することで設定を変更できます。 このメニューからできる操作は次のとおりです。

  • アクセスインターフェイスまたはシステム管理者が構成したホームページへのアクセス
  • ファイル転送ユーティリティの開始
  • 構成の変更
  • 接続ログの表示
  • Access Gateway Plug-inの現在のメッセージの表示
  • オンラインヘルプへのアクセス
  • Access Gateway Plug-inからのログオフと終了

管理者はAccess Gateway Plug-inを設定して、ユーザーがアクセスインターフェイス、ファイル転送ユーティリティ、または構成設定を使用できないようにすることができます。 管理者がそのようにAccess Gateway Plug-inを構成した場合は、それらの項目はメニューに表示されません。

アクセスインターフェイスへのアクセス

Citrixが提供するアクセスインターフェイスを使用すると、ほかのコンピューターへの接続をテストし、ブックマークを構成し、ファイルを転送し、Outlook Web AccessのようなWebベースの電子メールに接続することができます。 ホームページについて詳しくは、「アクセスインターフェイスの使用方法」を参照してください。

システム管理者はアクセスインターフェイスを無効にして、ホームページとして別のWebページを使用することがあります。 この節では、アクセスインターフェイスの使用方法について説明します。

  1. 通知領域のAccess Gatewayアイコンを右クリックして、［ホーム］を選択します。

Access Gateway Plug-inの情報と設定の表示と変更

通知領域のAccess Gatewayアイコンからアクセスするメニューから、［Citrix Access Gateway設定］ダイアログボックスを開くことができます。 Access Gateway接続の情報を表示したり、接続の設定を構成したりできます。

注： このダイアログボックスを開くには、ログオンしている必要があります。
  1. 通知領域のAccess Gatewayアイコンを右クリックして、［Access Gatewayを設定］を選択します。

接続の統計情報の表示

［Citrix Access Gateway設定］ダイアログボックスでは次の操作を行えます。

  • 接続の統計情報の表示
  • プロファイルの表示。プロファイルには、接続先のAccess Gatewayアプライアンスとネットワークや、そのほかの構成情報が含まれます。
  • Access Gateway接続のログ情報の構成
  • 接続の圧縮率の表示

［一般情報］タブには接続の情報が表示されます。 この情報は、接続に問題が発生したときにテクニカルサポート担当者が参照します。

注： 接続の統計情報にアクセスできないように、管理者がAccess Gatewayを構成している可能性があります。
  1. 通知領域のAccess Gatewayアイコンを右クリックして、［Access Gatewayを設定］を選択します。
  2. ［一般情報］タブをクリックします。

［プロファイル］タブでの設定変更

［Citrix Access Gateway設定］ダイアログボックスの［プロファイル］タブで、次の接続設定を変更できます。

  • 分割トンネリング、分割DNS、およびローカルエリアネットワークアクセス
  • 内部ネットワークの特定のリソースに接続するための、ドメインとIPアドレスの設定
  • アクセスを有効または無効にするネットワーク
  • ログオン時にWebブラウザーを使用せず、毎回Access Gateway Plug-inを使用するようにするコンピューターの設定
  • セキュリティ証明書の警告
