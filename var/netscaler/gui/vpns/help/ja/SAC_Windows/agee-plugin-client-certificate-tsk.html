クライアント証明書を使用したログオン

Access Gatewayへのログオンにクライアント証明書を使用する場合があります。 Access Gatewayにログオンするとき、証明書の詳細とシステム管理者がAccess Gatewayに構成した情報が照合されます。 詳細が一致する場合はログオンできます。 詳細が一致しない場合はログオンが拒否される可能性があります。

Access Gatewayでは、次のいずれかの場所にあるクライアント証明書を認証できます。

  • デバイスのWindowsオペレーティングシステムの証明書ストア。 クライアント証明書は、Microsoft管理コンソール（Microsoft Management Console：MMC）を使って別にインストールします。
  • スマートカードまたはハードウェアトークン。 スマートカードに組み込まれているクライアント証明書を、ネットワークに接続しているスマートカードリーダーで読み取ります。
  • アメリカ合衆国国防総省で識別と認証に使用されている、共通アクセスカード。

デバイスにクライアント証明書をインストールするには、システム管理者またはヘルプデスク担当者の指示に従います。

デバイスに複数のクライアント証明書をインストール済みである場合は、ログオンに使用する証明書を確認するメッセージがAccess Gateway Plug-inにより表示されます。

Internet ExplorerまたはAccess Gateway Plug-inのダイアログボックスを使用してログオンする場合は、Windows証明書ストアのクライアント証明書が使用されます。 Firefox Webブラウザーを使用してログオンする場合は、証明書をFirefoxにインポートする必要があります。

クライアント証明書をFirefoxにインポートするには

  1. Firefox Webブラウザーを開きます。
  2. ［ツール］メニューの［オプション］を選択します。
  3. ［詳細設定］をクリックします。
  4. ［証明書マネージャ］ダイアログボックスの［あなたの証明書］タブをクリックし、［インポート］をクリックします。
  5. コンピューター上の証明書に移動して［開く］をクリックします。

    証明書のパスワードの入力を求められる可能性があります。 パスワードについては、システム管理者またはヘルプデスク担当者に問い合わせてください。

  6. ［OK］をクリックします。

Firefoxへの証明書のインポートについて詳しくは、Firefoxのヘルプを参照してください。
