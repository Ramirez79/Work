コンピューター上のソフトウェアのスキャン

システム管理者が、コンピューター上のソフトウェア、ファイル、プロセス、およびそのほかの項目をスキャンするようにAccess Gatewayを構成する可能性があります。 このスキャン処理はエンドポイント解析と呼ばれます。 初めてログオンするときにEndpoint Analysis Plug-inが自動的にインストールされ、必要なソフトウェアまたはプロセスがあることを保証するためにデバイスがスキャンされます。 必要なソフトウェアまたはプロセスがない場合はログオンできない可能性があります。 その後は、ログオンするときにデバイスをスキャンするかどうかを選択できます。 スキャンを実行することをお勧めします。 スキャンをスキップすると、Access Gatewayにログオンできず、内部ネットワークのリソースに接続できない可能性があります。

ログオン後もEndpoint Analysis Plug-inによってデバイスがスキャンされる可能性があります。これにより、必要なソフトウェアが存在し続けていて、ネットワーク内で要件とされる最新バージョンがインストールされていることを保証します。 デバイスが要件を満たしていないことがわかった場合は、セッションが終了する可能性があります。
