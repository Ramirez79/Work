分割トンネリングの構成

分割トンネリングを有効にすると、接続先ネットワークのIPアドレスを使用して、Access Gatewayによりトラフィックがフィルターされます。 組織のネットワークを宛先とするトラフィックはAccess Gatewayを介して送信され、そのほかのトラフィックはLANまたはインターネットに送信されます。 分割トンネリングにより、Access Gatewayを経由するネットワークトラフィックがIPアドレスに基づいて制限されます。

たとえば、組織のネットワーク内のイントラネットWebサイトに接続すると、要求はAccess Gatewayに送信されます。 ニュースサイトなどの外部Webサイトに接続すると、ネットワークトラフィックはAccess Gatewayを経由して送信されません。

分割トンネリングには3つのオプションがあります。

  • オン： 分割トンネリングが有効なとき、接続先のIPアドレスおよびポートと、システム管理者がAccess Gatewayに構成した値がAccess Gateway Plug-inにより比較されます。 いずれかの値と一致した場合、パケットはAccess Gatewayを介してリモートネットワークに送信されます。 そうでなければ、パケットはLANに迂回されます。
  • オフ： ［オフ］を選択すると分割トンネリングは無効になり、Access Gateway Plug-inによりすべてのトラフィックがAccess Gatewayを介してリモートネットワークに送信されます。
  • リバースオン： ［リバースオン］を選択するとインターネット接続およびLANへの要求がAccess Gatewayを介して送信されます。 内部ネットワークリソースへの接続はAccess Gatewayを介して送信されません。 この設定は通常、Access Gatewayが内部ネットワーク内に存在し、ユーザーが組織内から接続する場合に使用されます。
重要： Access Gateway上で分割トンネリングが無効な場合は、分割トンネリングと分割DNSに関するAccess Gateway Plug-in側の制御が無効になり、ユーザーが設定を変更することはできません。 すべてのネットワークトラフィックがAccess Gatewayを介して送信されます。
  1. 通知領域のAccess Gatewayアイコンを右クリックして、［Access Gatewayを設定］を選択します。
  2. ［プロファイル］タブをクリックして［プロファイルを変更］をクリックします。
  3. ［接続］タブの［分割トンネリング］で、望ましいオプションをクリックして［OK］をクリックします。
