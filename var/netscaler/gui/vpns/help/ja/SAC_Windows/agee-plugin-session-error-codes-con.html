Access Gatewayセッションのエラーコード

次のエラーコードは、Access Gatewayのセッションウィンドウに表示されます。 これらのコードはAccess Gatewayの問題のトラブルシューティングに使用できます。

エラーコード 説明

0001-1000

通常の操作

1001-2000

内部エラー

2001-3000

Access Gateway Plug-inのエラー

3001-4000

Webブラウザーのエラー

次の表では、Access Gatewayセッションにより表示されるエラーコードとメッセージについて、そしてメッセージに対処するために実行すべき操作について説明します。

2019 エンドポイント解析に失敗したため、Access Gatewayへの接続を確立できません。 Access Gatewayによって、特定のソフトウェア、プロセス、またはファイルがユーザーデバイスに存在することが要件になっています。 ユーザーデバイスがエンドポイント解析の要件を満たさない場合は、ユーザーはログオンできません。 Access Gateway Plug-inを終了して、エンドポイント解析に合格するための正しい設定でユーザーデバイスを構成します。
