アクセスインターフェイスの使用方法

Access Gatewayにはアクセスインターフェイスが組み込まれています。これは次の図に示すようなホームページです。 このページには、組織のメンバーが最もよくアクセスするWebサイトとファイル共有が一覧表示されます。 管理者は［企業Webサイト］または［企業ファイル共有］に表示されるリンクを構成します。 ユーザーは［個人Webサイト］または［個人ファイル共有］に独自のブックマークを作成できます。 ここでは、アクセスインターフェイスで実行できる構成作業について説明します。

図 1. アクセスインターフェイスと呼ばれるAccess Gatewayのデフォルトホームページ
注： アクセスインターフェイスは、Access Gatewayと共に出荷されるデフォルトのホームページです。 システム管理者は別のホームページを使用できるので、ユーザーがログオンするときにアクセスインターフェイスが表示されない可能性があります。
