［ホーム］タブへのブックマークの追加

システム管理者はアクセスインターフェイスにブックマークを追加できます。 ブックマークは［企業Webサイト］にリンクとして表示されます。ユーザーも、よくアクセスするネットワークリソースへのブックマークを作成することができます。 SharePointサイトのようなイントラネットまたはインターネットのWebサイトや内部ネットワークのファイル共有へのリンクをブックマークにすることができます。 作成したリンクは［個人Webサイト］に表示されます。

  1. ［追加］をクリックします。
  2. ［名前］ボックスにリンクの名前を入力します。
  3. ［アドレス］ボックスにWebサイトのWebアドレスまたは内部Webサーバーのネットワークパスを入力します。
  4. ［説明］ボックスにリンクの説明を入力し、［追加］をクリックします。
注： Webアドレス（http://www.mycompany.com）とネットワークファイルパス（\\server\sharename）は、入力される形式に基づいてAccess Gatewayで自動的に区別されます。 リンクを作成するときに、リソースの種類を指定する必要はありません。

ブックマークの削除

ユーザーは［個人Webサイト］のブックマークを削除できますが、［企業Webサイト］のブックマークは削除できません。

  1. ［削除］をクリックします。
  2. ブックマークを選択して［削除］をクリックします。

［電子メール］タブの使用方法

［電子メール］タブではMicrosoft Outlook Web Accessを使用して電子メールにアクセスできます。 タブをクリックすると、ローカルにインストールしたOutlookを使用しているときのように電子メールが表示されます。

Outlook Web Accessを使用するには、システム管理者による構成が必要です。

［ファイル転送］タブを使用したファイル共有への接続

［ファイル転送］タブから内部ネットワークにログオンして、共有リソースにアクセスできます。

  1. アクセスインターフェイスの［ファイル転送］タブをクリックします。

Access Gatewayアイコンを使用した［ファイル転送］タブへのアクセス

  1. 通知領域のAccess Gatewayアイコンを右クリックして、［ファイルを転送］を選択します。

次に、［ファイル転送］タブのさまざまなコンポーネントについて説明します。

上パネルでの設定構成

ブラウザーウィンドウの上パネルにはいくつかのボタンがあり、ファイルの格納と転送についてさまざまな作業ができます。

  • ログオン： このボタンをクリックして、内部ネットワークまたはネットワーク上の特定のコンピューターにログオンします。
  • 上へ： このボタンをクリックして、上位のフォルダーに移動します。
  • 更新： このボタンをクリックして、アクティブなフォルダーの内容を更新します。
  • 新規フォルダー： このボタンをクリックして、新しいフォルダーを作成します。
  • ダウンロード： このボタンをクリックして、リモートサーバーから選択したファイルをダウンロードします。
  • アップロード： このボタンをクリックして、ユーザーデバイスから選択したファイルをリモートサーバー上のフォルダーにアップロードします。
  • 削除： このボタンをクリックして、リモートコンピューターから選択したファイルを削除します。
  • 名前の変更： このボタンをクリックして、ファイルまたはフォルダーの名前を変更します。
  • ログオフ： このボタンをクリックして、リモートサーバーから切断します。

左パネルでのフォルダーとファイルの表示

サーバー、そのディレクトリ、およびディレクトリ構造は、左パネルにツリー形式で表示されます。 プラス（+）アイコンをクリックしてフォルダーを表示します。

右パネルでのネットワークリソースへの接続

右パネルに［ファイルサーバー］ウィンドウが開きます。 このウィンドウを使用して、内部ネットワークのファイルサーバーにログオンします。 ファイルサーバーにアクセスするには、ファイル共有のアドレスを入力します。 必要に応じて、ユーザー名、パスワード、およびドメイン名も入力できます。 Access Gatewayへのログオン後にファイル共有にアクセスできている場合は、ユーザー名、パスワード、およびドメイン名の入力は不要である可能性があります。

  1. 通知領域のAccess Gatewayアイコンを右クリックして、［ファイルを転送］を選択します。
  2. ［アドレス］ボックスにファイル共有の名前を入力します。
  3. ユーザーの資格情報が必要な場合は、［アカウント情報を入力］をクリックして手順4.～7.を実行します。 不要な場合は、［ログオン］をクリックします。
  4. ［ユーザー名］ボックスにユーザー名を入力します。
  5. ［パスワード］ボックスにパスワードを入力します。
  6. ［ドメイン］ボックスに有効なドメイン名を入力します。
  7. ［ログオン］をクリックします。

リモートサーバーが特定のドメインに割り当てられていない場合は、［ドメイン］ボックスは空白のままにします。

注： このボックスを空白のままにすると、特定のサーバーではなく内部ネットワークにログオンします。

右パネルにサブフォルダーとファイルが表示されます。 アクティブなフォルダーの場所が［アドレス］ボックスに表示されます。
