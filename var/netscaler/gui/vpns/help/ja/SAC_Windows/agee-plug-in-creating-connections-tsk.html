Access Gateway Plug-inによる接続の作成

Access Gateway Plug-inに接続して使用するには、システム管理者から次の情報を得る必要があります。

  • https://AccessGatewayFQDN/のようなAccess GatewayのWebアドレス。
  • システム管理者が決定する、プラグインを実行するためのシステム要件。 システム要件には、コンピューターにインストールされているアンチウィルスソフトウェアまたはパーソナルファイアウォールが含まれる可能性があります。

コンピューターの構成によっては、次の追加要件を満たす必要がある可能性もあります。

  • Access Gateway Plug-inをインストールするには、プログラムをコンピューターにインストールするためローカルの管理者つまりAdministratorsグループのメンバーである必要があります。
  • コンピューター上でパーソナルファイアウォールを使用している場合は、プラグインに初めて接続するときに、接続を許可するかどうかを確認するメッセージがファイアウォールによって表示される可能性があります。 このメッセージが表示された場合は、常に接続を許可します。 接続の許可について詳しくは、製造元のドキュメントを参照してください。

Webアドレスを使用した接続

Webアドレスを使用して接続しようとすると、ログオンページか、Access Gateway Plug-inを使用して接続できるポータルページが直接開きます。

Access Gatewayの構成のため、プラグインで接続する前にユーザーがログオンする必要がある場合は、ユーザー名とパスワードを入力してログオンします。 Webページが開き、プラグインをダウンロードしてインストールできます。 Access Gateway Plug-inをインストールすると、ユーザーが使用する許可を持つネットワークリソースに完全にアクセスできるようになります。

Access Gateway Plug-inのダウンロードとインストール

セキュリティで保護された接続を初めて実行するときは、Webブラウザーを使用してAccess Gatewayにログオンします。 管理者に、Webアドレスとログオン用の資格情報を確認します。 通常、Webアドレスはhttps://ag.companyname.comという形式です。

  1. WebブラウザーにAccess GatewayのWebアドレスを入力します。
  2. ユーザー名とパスワードを入力して、［ログオン］をクリックします。
  3. プラグインをインストールするには［ネットワークアクセス］をクリックします。

ダウンロードが完了するとプラグインが接続し、タスクバーの通知領域にメッセージが表示されます。 通知領域のAccess Gatewayアイコンを使用してログオンすることもできます。

Access Gateway Plug-inのダイアログボックスを使用した接続

Webブラウザーを使用せずにAccess Gateway Plug-inを使用して接続する場合は、通知領域のアイコンをクリックしたときにログオンダイアログボックスを開くようにプラグインを構成できます。

注： Access Gateway Plug-inのオプションを構成するには、ログオンしている必要があります。
  1. 通知領域のAccess Gatewayアイコンを右クリックして、［Access Gatewayを設定］を選択します。
  2. ［プロファイル］タブをクリックして［プロファイルを変更］をクリックします。
  3. ［オプション］タブで［ログオンにAccess Gateway Plug-inを使用する］チェックボックスをオンにします。

デスクトップのAccess Gatewayアイコンをダブルクリックするか、タスクバーの通知領域のAccess Gatewayアイコンを右クリックし［ログオン］を選択して、ログオンすることができます。 Access Gateway Plug-inの構成について詳しくは、「［詳細オプション］ショートカットメニューを使用した設定変更」を参照してください。
