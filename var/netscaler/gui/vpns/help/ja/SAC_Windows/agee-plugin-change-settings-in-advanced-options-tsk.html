［詳細オプション］ショートカットメニューを使用した設定変更

Access Gateway Plug-inのダイアログボックスでは、次の設定を変更できます。

  • Access GatewayのIPアドレスまたはWebアドレス
  • プロキシサーバーの設定
  • セキュリティ証明書の警告
注： これらの設定は、Webブラウザーではなく［Citrix Access Gateway］ダイアログボックスを使用してログオンするようにAccess Gateway Plug-inを構成した場合にのみ変更できます。 詳しくは、「Access Gateway Plug-inによる接続の作成」を参照してください。

Access GatewayのWebアドレスの設定

Access Gateway Plug-inを構成するとき、ユーザーはあらかじめ構成されたAccess GatewayのIPアドレスを使用して接続します。 別のアプライアンスに接続するようにプラグインを構成することもできます。

  1. 通知領域のAccess Gatewayアイコンを右クリックして、［ログオン］を選択します。
  2. ［Citrix Access Gateway］ダイアログボックス内の任意の場所を右クリックし、［詳細オプション］を選択します。
  3. ［Citrix Access Gateway設定］の［Webアドレス］ボックスにWebアドレスを入力して、［OK］をクリックします。

    ［Webアドレス］ボックスには、192.168.1.2のようなIPアドレスまたはhttps://ag1.mycompany.comのようなWebアドレスを指定できます。

Access Gateway Plug-in用のプロキシサーバーの構成

プロキシサーバーは、デバイスと内部ネットワーク内のサーバーの間に位置するコンピューターです。 プロキシサーバーはWebブラウザーから内部ネットワーク内のサーバーへの要求を傍受し、要求されたWebページを処理できるかどうかを確認します。 プロキシサーバーで要求を満たせない場合は、セキュリティが保護されたネットワーク内のサーバーに要求が送られます。

プロキシサーバーを手作業で構成する場合は、プロキシ設定の自動検出は無効になります。

  1. 通知領域のAccess Gatewayアイコンを右クリックして、［ログオン］を選択します。
  2. ［Citrix Access Gateway］ダイアログボックス内の任意の場所を右クリックし、［詳細オプション］を選択します。
  3. ［プロキシ設定］の［プロキシサーバーを手動で設定する］チェックボックスをオンにします。
  4. ［IPアドレス］ボックスと［ポート］ボックスに、IPアドレスとポート番号を入力します。
注： ログオンダイアログボックスを開き［詳細オプション］を選択してプロキシを構成するには、Access Gatewayからログオフする必要があります。

セカンダリパスワードを使用したログオン

2種類の認証を使用してログオンする必要があるAccess Gatewayアプライアンスを使用する場合があります。 その場合は、ユーザー名、パスワード、およびRSA SecurIDのトークン番号のようなトークン生成の数値を付加した個人識別番号（PIN）を入力する可能性があります。

デフォルトでは、［Citrix Access Gateway］ダイアログボックスにはユーザー名とパスワードを入力するボックスが表示されます。 セカンダリパスワードのボックスを表示するように、Access Gateway Plug-inを構成することができます。

  1. 通知領域のAccess Gatewayアイコンを右クリックして、［ログオン］を選択します。
  2. ダイアログボックス内の任意の場所を右クリックし、［セカンダリパスワードを表示］を選択します。
注： ［セカンダリパスワード］ボックスを表示する必要がない場合は、［Citrix Access Gateway］ダイアログボックス内の任意の場所を右クリックし、［セカンダリパスワードを非表示］を選択します。
