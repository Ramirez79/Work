Access Gateway Plug-inセッションの完了

Access Gateway Plug-inセッションは次の2つの方法で完了できます。

  • Access Gatewayからのログオフ
  • セッションの終了

Access Gatewayからログオフするには

ログオフするとセッションが完了し、通知領域にAccess Gatewayアイコンが残ります。

Access Gatewayからログオフする方法は2種類あります。

  • アクセスインターフェイスで［ログオフ］をクリックします。
  • 通知領域のAccess Gatewayアイコンを右クリックして、［ログオフ］を選択します。

セッションを終了するには

セッションを終了するとセッションが完了し、通知領域のAccess Gatewayアイコンが削除されます。

  • 通知領域のAccess Gatewayアイコンを右クリックして、［終了］を選択します。
