Logging On with a Client Certificate

You might log on to Access Gateway using a client certificate. When you log on to Access Gateway, your details in the certificate are matched against information that your system administrator configured on Access Gateway. If the details match, you can log on. If the details do not match, log on might be denied.

Access Gateway can authenticate a client certificate that is stored in one of these locations:

  • In the certificate store of the Windows operating system on your device. In this case, the client certificate is installed separately in the certificate store using the Microsoft Management Console.
  • In a smart card or a hardware token. In this case, the certificate is embedded within the smart card and read from a smart card reader attached to the network.
  • In a common access card that the United States Department of Defense uses for identification and authentication.

To install the client certificate on your device, follow the instructions provided by your system administrator or Help desk personnel.

If you have multiple client certificates installed on your device, the Access Gateway Plug-in prompts you to select the correct certificate to log on.

If you log on using Internet Explorer or the Access Gateway Plug-in dialog box, the client certificate is used from the Windows certificate store. If you log on using the Firefox Web browser, you need to import the certificate to Firefox.

To import a client certificate to Firefox

  1. Open the Firefox Web browser.
  2. On the menu, click Tools and then click Options.
  3. Click Advanced.
  4. In the Certificate Manager dialog box, click Your Certificates and then click Import.
  5. Navigate to the certificate stored on your computer and then click Open.

    You might be asked for a password for the certificate. Contact your system administrator or Help desk personnel for the password.

  6. Click OK.

For more information about importing certificates to Firefox, see the Firefox Help.
