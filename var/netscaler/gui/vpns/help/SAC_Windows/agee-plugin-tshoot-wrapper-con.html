Troubleshooting the Access Gateway Plug-in

The Access Gateway Plug-in for Windows provides tools to help you troubleshoot your connections and sessions. You can use a variety of statistics and logs to report problems to your Help desk or system administrator.

The Access Gateway Plug-in provides logs that you can send to your Help desk personnel to evaluate for problems you have with the Access Gateway Plug-in and logging on to Access Gateway. You can also view compression statistics that provide information about your connection.
