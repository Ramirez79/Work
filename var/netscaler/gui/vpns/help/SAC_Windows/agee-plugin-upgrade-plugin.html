Upgrading the Access Gateway Plug-in

The Access Gateway Plug-in for Windows upgrades automatically when a new version of the software is available. When you log on to Access Gateway, the appliance detects the plug-in version installed on your device. If the plug-in version does not match the version on Access Gateway, the software is upgraded on your computer automatically. When the upgrade is complete, you can then log on to Access Gateway and connect to network resources in the internal network.

If your system administrator configures Access Gateway to scan your computer for software, files, processes, and other items, the Endpoint Analysis Plug-in installs automatically and scans your computer for the required software. The Endpoint Analysis Plug-in also upgrades automatically when a new version becomes available.

If you can connect to more than one Access Gateway appliance, the software version that runs on each appliance might be different. For example, ag1 might have a newer version of the Access Gateway software than the ag2 appliance. If you originally connect to ag1, end the session and then connect to ag2, the Access Gateway Plug-in and Endpoint Analysis Plug-in downgrade automatically to the version on ag2.
