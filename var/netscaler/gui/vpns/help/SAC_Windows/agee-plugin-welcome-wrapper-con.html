Access Gateway Plug-in for Windows User Guide

Before logging on using the Citrix Access Gateway Plug-in for Windows, review this user guide to learn how your connections work and how to access network resources in the secure network.

This user guide is intended for users who log on to the internal network through an Access Gateway appliance. This guide assumes that the Access Gateway appliance is connected to an existing network and that your system administrator configured the appliance for user connections.
