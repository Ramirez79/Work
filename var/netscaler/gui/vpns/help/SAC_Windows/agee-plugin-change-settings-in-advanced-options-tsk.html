Changing Settings in the Advanced Options Dialog Box

In the Access Gateway Plug-in dialog box, you can change the following settings:

  • The IP address or Web address for Access Gateway
  • Proxy server settings
  • Security certificate warnings
Note: You can only change these settings if you have configured the Access Gateway Plug-in to log on using the Access Gateway dialog box instead of a Web browser. For more information, see Creating Connections Using the Access Gateway Plug-in.

Setting the Access Gateway Web Address

When the Access Gateway Plug-in is configured, you use the preconfigured IP address of Access Gateway to connect. You can also configure the plug-in to connect to a different appliance.

  1. In the notification area, right-click the Access Gateway Plug-in icon and then click Logon.
  2. In the Citrix Access Gateway logon dialog box, right-click anywhere in the dialog box and then click Advanced Options.
  3. Under Citrix Access Gateway configuration, in Web address, type the Web address and then click OK.

    The Web address can be an IP address, such as 192.168.1.2, or Web address such as https://ag1.mycompany.com.

Configuring Proxy Servers for the Access Gateway Plug-in

A proxy server is a computer that sits between your device and servers in the internal network. Proxy servers intercept requests from your Web browser to the server in the internal network to see if the proxy server can fulfill the requested Web page. If the proxy server cannot fulfill the request, the server sends the request to the server in the secure network.

When you manually configure a proxy server, automatic detection of proxy settings is disabled.

  1. In the notification area, right-click the Access Gateway icon and then click Logon.
  2. In the Citrix Access Gateway logon dialog box, right-click anywhere in the dialog box and then click Advanced Options.
  3. Under Proxy settings, select Manually configure proxy server.
  4. In IP Address and Port, type the IP address and port number.
Note: To access the logon dialog box and Advanced Options to configure proxy settings, you must log off from Access Gateway.

Logging On with a Secondary Password

Some Access Gateway appliances might require you to log on using two authentication types. These types might include your user name, password and a personal identification number (PIN) followed by a number from a token, such as an RSA SecurID token number.

The Access Gateway dialog box default setting is to display logon fields for your user name and password. You can configure the Access Gateway Plug-in to show the secondary password field.

  1. In the notification area, right-click the Access Gateway icon and then click Open.
  2. Right-click anywhere in the dialog box and then click Show Secondary Password.
Note: If you don't need to display the secondary password field, in the Access Gateway dialog box, right-click anywhere in the dialog box and then click Hide Secondary Password.
