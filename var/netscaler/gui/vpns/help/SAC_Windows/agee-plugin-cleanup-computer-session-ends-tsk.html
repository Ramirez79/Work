Cleaning Up Your Computer When Your Session Ends

During a session, temporary files are created on your computer. Access Gateway has a cleanup feature to remove temporary files from your computer. Your system administrator enables this feature.

You can select the following items for cleanup, which removes them from your computer:

  • Access Gateway Plug-in
  • Certificates used for authentication
  • Applications used during the session
  • Passwords and autocomplete data
  • History and Web addresses typed in the address bar
  • Cookies and temporary files

Finding Information on the Summary Tab

The Summary tab provides the following information about your session:

  • Total number of registry entries changed
  • Total number of cookies installed
  • Total number of applications used

Configuring the Cleanup Level

You can configure Access Gateway to delete some or all of the data sets when you log off. You might want to retain some of the data, such as autocomplete data, stored passwords, and history, especially if you are using your personal computer. Data is categorized into the following three groups to help you selectively delete data:

None. When you select this level, none of the data sets is deleted.

Browser Only. When you select this level, you can set Access Gateway to delete one or more of the following data sets:

  • Passwords and autocomplete data stored by the browser
  • History and Web addresses typed in the address bar
  • Browser cache cookies and temporary files

Everything. When you select this level, you can set Access Gateway to delete all temporary data that your computer generated.

Configuring the Cleanup Process

Your system administrator controls the cleanup process. The cleanup dialog box appears only if the administrator configured Access Gateway to display the dialog box. In addition, the administrator can also configure Access Gateway to delete specific data sets from your computer when you exit the session. The options corresponding to these data sets are disabled on the List tab of the Citrix Windows Cleanup dialog box. The remaining options are enabled or disabled based on the cleanup level you choose.

  1. In the Citrix Windows Cleanup dialog box, click List.
  2. Select or clear the check box next to the data set.

Viewing the Cleanup Logs

The Access Gateway Plug-in logs all the cleanup activity in a file that is stored on your hard drive. The file lists the action performed and the files that were deleted.

  1. On the Summary tab, click View Log.
