Ending Access Gateway Plug-in Sessions

You can end your session with the Access Gateway Plug-in in one of the following ways:

  • Logging off from Access Gateway
  • Exiting the session

To log off from Access Gateway

When you log off, the session ends and the Access Gateway icon remains in the notification area.

There are two ways you can log off from Access Gateway:

  • Click Log Off in the Access Interface.
  • Right-click the Access Gateway icon in the notification area and then click Logoff.

To exit the session

When you exit a session, the session ends and the Access Gateway icon is removed from the notification area.

  • Right-click the Access Gateway icon in the notification area and then click Exit.
