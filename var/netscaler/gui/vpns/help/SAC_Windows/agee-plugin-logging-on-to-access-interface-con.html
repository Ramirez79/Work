Logging On to the Access Interface

You can log on to the home page several different ways, depending on how your system administrator configured the Access Gateway appliance. The Access Interface or a custom home page that your system administrator installed may appear. If you type in a Web address after logging on, you might see one of the following three options:

  • Citrix XenApp
  • Clientless access
  • Network Access

Citrix XenApp provides access to applications that reside in your organization's network. Your system administrator can publish any type of application, such as Microsoft Word or Outlook.

If you selected Citrix XenApp, you are logged on and a list of your published applications appears.

If you log on using clientless access or with the Access Gateway Plug-in (by clicking Network Access) and your administrator configured published applications on Access Gateway, the Access Interface home page appears with your published applications in the left pane.
