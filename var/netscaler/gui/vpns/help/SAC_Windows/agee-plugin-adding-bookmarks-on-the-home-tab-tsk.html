Adding Bookmarks on the Home Tab

Your system administrator can add bookmarks to the Access Interface. These bookmarks appear as links under Enterprise Web Sites.You can also create your own bookmarks to commonly accessed network resources. These bookmarks can be links to either intranet sites, such as a SharePoint site, or to Internet Web sites or file shares in the internal network. The links that you create appear under Personal Web Sites.

  1. Click Add.
  2. In Name, type the name for the link.
  3. In Address, type the Web address of the Web site or the network path to the internal Web server.
  4. In Description, type a description for the link and then click Add.
Note: Access Gateway differentiates automatically between Web addresses and network file paths based on the format in which they are entered, such as http://www.mycompany.com or \\server\sharename. When creating a link, you do not need to specify the resource type.

Removing a Bookmark

You can remove bookmarks that are listed under Personal Web Sites, but not bookmarks listed under Enterprise Web Sites.

  1. Click Remove.
  2. Select the bookmark and then click Remove.

Using the Email Tab

The email tab provides you with access to your email using Microsoft Outlook Web Access. When you click the tab, your email appears as if you were using a local version of Outlook.

To use Outlook Web Access, your system administrator must configure the application.

Connecting to File Shares Using the File Transfer Tab

The File Transfer tab allows you to log on to the internal network and access shared resources.

  1. In the Access Interface, click the File Transfer tab.

Opening the File Transfer tab Using the Access Gateway Icon

  1. In the notification area, right-click the Access Gateway icon and then click Transfer Files.

The following sections cover the various components of the File Transfer tab.

Configuring Settings in the Top Panel

The top panel of the browser window includes several buttons that allow you to perform various tasks for storing and transferring files.

  • Log On. Click this button to log on to the internal network or a specific computer on the network.
  • Up. Click this button to navigate to the previous folder.
  • Refresh. Click this button to refresh the contents of the active folder.
  • New Folder. Click this button to create a new folder.
  • Download. Click this button to download the selected file from the remote server.
  • Upload. Click this button to upload the selected file from the user device to a folder on the remote server.
  • Delete. Click this button to delete the selected file from the remote computer.
  • Rename. Click this button to change the name of a file or folder.
  • Log Off. Click this button to disconnect from the remote server.

Viewing Folders and Files in the Left Panel

The servers, their directories, and the directory structure appears in a tree format in the left panel. Click the plus (+) icon to view folders.

Connecting to Network Resources in the Right Panel

The right panel displays the File Server window. Use this window to log on to a file server in the internal network. To access the file server, type the address of the file share. You can also enter your user name, password, and domain name if required. If you have access to the file share after logging on to Access Gateway, you might not need to enter your user name and password or the domain name.

  1. In the notification area, right-click the Access Gateway icon and then click Transfer Files.
  2. In Address, type the name of the file share.
  3. If your user credentials are required, click Enter Credentials and complete steps 4 through 7. Otherwise, click Log On.
  4. In User name, type your user name.
  5. In Password, type your password.
  6. In Domain, type a valid domain name.
  7. Click Log On.

If the remote server is not assigned a specific domain, leave the Domain field blank.

Note: If you leave this field blank, you are logged on to the internal network and not to a specific server.

The right panel now displays the subfolders and files. The location of the active folder appears in the Address field.
