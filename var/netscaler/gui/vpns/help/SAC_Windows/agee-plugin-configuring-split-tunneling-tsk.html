Configuring Split Tunneling

When split tunneling is enabled, Access Gateway filters traffic using the IP address of the destination network. Traffic meant for your organization’s network is sent through Access Gateway and the rest of the traffic is sent to your local area network (LAN) or the Internet. Split tunneling limits the network traffic through Access Gateway based on the IP address.

For example, you connect to an intranet Web site within your organizations network and the request goes to Access Gateway. If you connect to a Web site that is an external Web site, such as cnn.com, the network traffic does not go through Access Gateway.

Split tunneling has three options:

  • On. When split tunneling is enabled, the Access Gateway Plug-in compares the destination IP address and port against the values that the system administrator configured on Access Gateway. If one of the values match, the packets are sent to the remote network through Access Gateway. If not, the packets are diverted to your LAN.
  • Off. When you choose the Off option, split tunneling is disabled and the Access Gateway Plug-in sends all traffic to the remote network through Access Gateway.
  • Reverse On. When Reverse On is enabled, Internet connections and requests to your LAN are sent through Access Gateway. Connections to internal network resources are not sent through Access Gateway. This setting is typically used when Access Gateway resides in the internal network and you are connecting from your office.

Important: If split tunneling is disabled on Access Gateway, the corresponding controls for split tunneling and split DNS are disabled in the Access Gateway Plug-in and you cannot change the settings. All network traffic is sent through Access Gateway.

  1. Right-click the Access Gateway Plug-in icon in the notification area and then click Configure Access Gateway.
  2. Click the Profile tab and then click Change Profile.
  3. On the Connections tab, under Split tunneling, select the option you want and then click OK.
