Finalización de las sesiones de Access Gateway Plug-in

Es posible finalizar la sesión con Access Gateway Plug-in de las siguientes maneras:

  • Cerrar la sesión de Access Gateway
  • Salir de la sesión

Para cerrar la sesión de Access Gateway

Cuando se cierra la sesión, la sesión finaliza y el icono de Access Gateway permanece en el área de notificación.

Existen dos maneras de cerrar sesión en Access Gateway:

  • Haga clic en Cierre de sesión en Access Interface.
  • Haga clic con el botón secundario del mouse en el icono de Access Gateway en el área de notificación y, a continuación, haga clic en Cierre de sesión.

Para salir de la sesión

Al salir de la sesión, la sesión finaliza y el icono de Access Gateway desaparece del área de notificación.

  • Haga clic con el botón secundario del mouse en el icono de Access Gateway en el área de notificación y, a continuación, haga clic en Salir.
