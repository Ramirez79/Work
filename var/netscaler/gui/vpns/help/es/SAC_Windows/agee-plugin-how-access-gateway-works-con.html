Cómo funciona Access Gateway

Para iniciar sesión en la red interna de la empresa, es necesario iniciar sesión en Access Gateway. Para ello, debe utilizar Access Gateway Plug-in. Si intenta iniciar sesión en una red interna, instale el complemento en su equipo y, a continuación, inicie sesión.

Access Gateway Plug-in se instala en su equipo la primera vez que inicia sesión. Una vez instalado el plug-in, puede iniciar sesión mediante el icono que se encuentra en su escritorio, o bien, puede conectarse a través de una página del portal Web.

Después de descargar Access Gateway Plug-in en su equipo y establecer la conexión, Access Gateway crea un canal de comunicación seguro entre su equipo y Access Gateway que le permite acceder a los recursos de la red interna que puede utilizar.

El administrador del sistema puede configurar Access Gateway Plug-in para asegurar el funcionamiento de determinados servidores de seguridad personal y aplicaciones antivirus en su equipo.
