Cambio de parámetros desde el menú de Access Gateway

Una vez iniciada la sesión, puede cambiar los parámetros desde el icono de Access Gateway en el área de notificación al hacer clic con el botón secundario del mouse sobre el icono. A continuación, debe seleccionar un elemento del menú de Access Gateway. En este menú, podrá:

  • Abrir Access Interface o la página de inicio configurada por el administrador del sistema
  • Iniciar el programa de transferencia de archivos
  • Cambiar los parámetros de configuración
  • Abrir el registro de conexión
  • Mostrar el mensaje actual de Access Gateway Plug-in
  • Abrir la ayuda en línea
  • Cerrar sesión y salir de Access Gateway Plug-in

El administrador puede configurar Access Gateway Plug-in para que el usuario no pueda acceder a Access Interface, al programa de transferencia de archivos o a los parámetros de configuración. Si el administrador configuró Access Gateway Plug-in de esta manera, estos elementos no aparecerán en el menú.

Cómo abrir Access Interface

Access Interface, suministrado por Citrix, le permite probar conexiones en otros equipos, configurar marcadores, transferir archivos y conectarse al correo electrónico basado en la Web, como Outlook Web Access. Para obtener más información sobre la página de inicio, consulte Cómo trabajar con Access Interface.

Es posible que el administrador del sistema desactive Access Interface y utilice una página Web diferente como página de inicio. Esta sección describe cómo trabajar con Access Interface.

  1. En el área de notificación, haga clic con el botón secundario del mouse en el icono de Access Gateway y, a continuación, haga clic en Inicio.

Visualización y cambio de parámetros e información de Access Gateway Plug-in

Puede utilizar el menú disponible mediante el icono de Access Gateway en el área de notificación para abrir el cuadro de diálogo Configuración de Citrix Access Gateway. Puede visualizar la información sobre la conexión de Access Gateway y configurar los parámetros para las conexiones.

Nota: Debe iniciar sesión para abrir el cuadro de diálogo.
  1. Haga clic con el botón secundario del mouse en el icono de Access Gateway en el área de notificación y, a continuación, haga clic en Configurar Access Gateway.

Visualización de estadísticas de conexión

En el cuadro de diálogo Configuración, podrá:

  • Ver estadísticas de conexión
  • Ver su perfil, como el dispositivo de Access Gateway al que está conectado, las redes a las que puede conectarse y otros parámetros de configuración
  • Configurar información de registro para la conexión con Access Gateway
  • Ver información sobre compresión de conexión

La ficha General muestra información sobre la conexión. Esta información resulta de gran ayuda para el personal de asistencia técnica en caso de que experimente problemas con su conexión.

Nota: es posible que el administrador haya configurado Access Gateway de manera tal que impida el acceso a las estadísticas de conexión.
  1. En el área de notificación, haga clic con el botón secundario del mouse en el icono de Access Gateway y, a continuación, haga clic en Configurar Access Gateway.
  2. Haga clic en la ficha General.

Cambio de parámetros en la ficha Perfil

En el cuadro de diálogo Configuración, en la ficha Perfil, puede cambiar los siguientes parámetros de conexión:

  • Túnel dividido, DNS dividida y acceso a la red de área local
  • Parámetros de dominios y direcciones IP para establecer la conexión con recursos específicos en la red interna
  • Redes para habilitar o deshabilitar el acceso
  • Parámetros de configuración del equipo para habilitar la posibilidad de iniciar sesión en Access Gateway Plug-in sin utilizar el explorador Web
  • Advertencias de certificados de seguridad
