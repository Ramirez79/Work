Creación de conexiones a través de Access Gateway Plug-in

Para conectarse con Access Gateway Plug-in y utilizarlo, el administrador del sistema debe proporcionarle la siguiente información:

  • Dirección Web de Access Gateway; por ejemplo, https://AccessGatewayFQDN/.
  • Todos los requisitos de sistema para ejecutar el plug-in según lo haya determinado el administrador del sistema. Estos requisitos pueden incluir un software antivirus o un servidor de seguridad personal instalado en el equipo.

Según la configuración del equipo, tal vez necesite cumplir algunos requisitos adicionales:

  • Para instalar Access Gateway Plug-in, debe ser un administrador local o un miembro del grupo Administradores que puede instalar programas en el equipo.
  • Si utiliza un servidor de seguridad personal en el equipo, la primera vez que se conecte al plug-in, el servidor de seguridad le solicitará permiso para establecer la conexión. Si aparece esta solicitud, permita siempre la conexión. Para obtener información detallada sobre los permisos de conexión, consulte la documentación del fabricante.

Conexión a través de una dirección Web

Si se conecta a través de una dirección Web, se le indicará que inicie sesión o se lo dirigirá directamente a una página de portal en la que podrá conectarse mediante Access Gateway Plug-in.

Si la configuración de Access Gateway lo obliga a iniciar sesión antes de establecer la conexión con el plug-in, escriba su nombre de usuario y su contraseña y, luego, inicie sesión. Aparecerá una página Web que permite descargar e instalar el plug-in. Una vez instalado Access Gateway Plug-in, la conexión permite el acceso completo a los recursos de red que está autorizado a utilizar.

Descarga e instalación de Access Gateway Plug-in

Para establecer una conexión segura por primera vez, inicie sesión en Access Gateway a través de un explorador Web. Para obtener la dirección Web y las credenciales de inicio de sesión, comuníquese con el administrador. El formato típico de una dirección Web es https://ag.nombredelaempresa.com.

  1. En un explorador Web, escriba la dirección Web de Access Gateway.
  2. Escriba su nombre de usuario y contraseña y, luego, haga clic en Inicio de sesión.
  3. A continuación, haga clic en Acceso de red para instalar el plug-in.

Una vez completada la descarga, el plug-in se conecta y aparece un mensaje en el área de notificación de la barra de tareas. También puede iniciar sesión mediante el icono de Access Gateway que se encuentra en el área de notificación.

Conexión mediante el cuadro de diálogo Access Gateway Plug-in

Si desea conectarse mediante Access Gateway Plug-in sin utilizar un explorador Web, puede configurar el plug-in para que muestre el cuadro de diálogo de inicio de sesión cuando haga clic en el icono del área de notificación.

Nota: Para configurar los parámetros de Access Gateway Plug-in, primero debe iniciar sesión.
  1. En el área de notificación, haga clic con el botón secundario del mouse en el icono de Access Gateway y, a continuación, haga clic en Configurar Access Gateway.
  2. Haga clic en la ficha Perfil y, a continuación, haga clic en Cambiar perfil.
  3. En la ficha Opciones, haga clic en Utilice Access Gateway Plug-in para el inicio de sesión.

Para iniciar sesión, haga doble clic en el icono de Access Gateway ubicado en el escritorio, o bien, haga clic con el botón secundario del mouse en el icono de Access Gateway que se encuentra en el área de notificación de la barra de tareas y, a continuación, haga clic en Inicio de sesión. Para obtener más información sobre la configuración de Access Gateway Plug-in, consulte Cambio de parámetros en el cuadro de diálogo Opciones avanzadas.
