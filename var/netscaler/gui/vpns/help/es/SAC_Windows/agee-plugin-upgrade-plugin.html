Actualización de Access Gateway Plug-in

Access Gateway Plug-in para Windows se actualiza automáticamente cuando se encuentra disponible una nueva versión del software. Cuando se inicia sesión en Access Gateway, el dispositivo detecta la versión del plug-in instalada en su dispositivo. Si la versión del plug-in no coincide con la versión de Access Gateway, el software se actualiza en el equipo automáticamente. Una vez finalizada la actualización, puede iniciar sesión en Access Gateway y conectarse a los recursos de red de la red interna.

Si el administrador del sistema configura Access Gateway para que detecte productos de software, archivos, procesos y otros elementos en el equipo, Endpoint Analysis Plug-in se instala de forma automática y busca el software necesario en el equipo. Además, Endpoint Analysis Plug-in se actualiza automáticamente cuando se encuentra disponible una versión nueva.

Si el usuario se puede conectar a varios dispositivos Access Gateway, es posible que la versión del software que se ejecuta en cada dispositivo sea diferente. Por ejemplo, el dispositivo ag1 podría tener una versión más reciente del software Access Gateway que el dispositivo ag2. Si originalmente se conectó al dispositivo ag1, cierre la sesión y luego, conéctese al dispositivo ag2, ya que Access Gateway Plug-in y Endpoint Analysis Plug-in vuelven a la versión anterior del dispositivo ag2 automáticamente.
