Detección de software en el equipo

Es posible que el administrador del sistema configure Access Gateway para que detecte productos de software, archivos, procesos y otros elementos en su equipo. Este proceso de detección se denomina análisis de seguridad. Al iniciar sesión por primera vez, Endpoint Analysis Plug-in se instala automáticamente y explora el dispositivo para asegurarse de que cuenta con el software o los procesos necesarios. Si no cuenta con el software o los procesos necesarios, es posible que no pueda iniciar sesión. Posteriormente, al iniciar sesión, puede elegir si desea explorar el dispositivo o si desea omitir la exploración. Se recomienda que se realice la exploración. Si omite la exploración, es posible que no pueda iniciar sesión en Access Gateway y que no pueda conectarse a los recursos en la red interna.

Endpoint Analysis Plug-in también puede explorar su dispositivo después de iniciar sesión para asegurarse de que tiene instalado el software y la versión más reciente que requiere su red. Si el dispositivo no cumple con los requisitos necesarios, es posible que se finalice la sesión.
