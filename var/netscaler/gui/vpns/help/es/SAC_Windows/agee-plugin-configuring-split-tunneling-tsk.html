Configuración de túnel dividido

Cuando el túnel dividido está activado, Access Gateway filtra el tráfico mediante la dirección IP de la red de destino. El tráfico dirigido a la red de la organización se envía a través de Access Gateway y el resto del tráfico se envía a la red de área local (LAN) o Internet. El túnel dividido limita el tráfico de red a través de Access Gateway de acuerdo con la dirección IP.

Por ejemplo, si se conecta a un sitio Web de Intranet dentro de la red de su organización, la solicitud se dirige a Access Gateway. Si se conecta a un sitio Web externo, como cnn.com, el tráfico de red no pasa por Access Gateway.

El túnel dividido presenta tres opciones:

  • Activado. Cuando el túnel dividido está habilitado, Access Gateway Plug-in compara el puerto y la dirección IP de destino con los valores configurados por el administrador del sistema en Access Gateway. Si uno de los valores coincide, los paquetes se envían a la red remota a través de Access Gateway. Si no, los paquetes se desvían a su LAN.
  • Desactivado. Al elegir la opción Desactivado, se desactiva el túnel dividido y Access Gateway Plug-in envía todo el tráfico a la red remota a través de Access Gateway.
  • Inversa activada. Cuando la opción Inversa activada está habilitada, las conexiones a Internet y las solicitudes para su LAN se envían a través de Access Gateway. Las conexiones a los recursos internos de la red no se envían a través de Access Gateway. Esta configuración se utiliza comúnmente cuando Access Gateway reside en la red interna y el usuario se conecta desde su oficina.
Importante: si el túnel dividido está desactivado en Access Gateway, se desactivan los controles correspondientes para el túnel dividido y la división DNS en Access Gateway Plug-in. Esta configuración no se puede cambiar. Todo el tráfico de red se envía a través de Access Gateway.
  1. Haga clic con el botón secundario del mouse en el icono de Access Gateway Plug-in en el área de notificación y, a continuación, haga clic en Configurar Access Gateway.
  2. Haga clic en la ficha Perfil y, a continuación, haga clic en Cambiar perfil.
  3. En la ficha Conexiones, en Túnel dividido, seleccione la opción que desea y, a continuación, haga clic en Aceptar.
