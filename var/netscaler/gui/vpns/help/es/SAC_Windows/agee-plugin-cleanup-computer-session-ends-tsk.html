Limpieza del equipo cuando finaliza la sesión

Durante una sesión se crean archivos temporales en su equipo. Access Gateway cuenta con una función de limpieza para quitar los archivos temporales del equipo. El administrador del sistema es quien habilita esta función.

Puede seleccionar los siguientes elementos para limpieza, que se eliminarán del equipo:

  • Access Gateway Plug-in
  • Certificados utilizados para la autenticación
  • Aplicaciones utilizadas durante la sesión
  • Contraseñas y datos que se completan automáticamente
  • Historial y direcciones Web escritos en la barra de direcciones
  • Cookies y archivos temporales

Búsqueda de información en la ficha Resumen

La ficha Resumen proporciona la siguiente información sobre su sesión:

  • Cantidad total de entradas en el registro que se modificaron
  • Cantidad total de cookies que se instalaron
  • Cantidad total de las aplicaciones que se usaron

Configuración del nivel de limpieza

Puede configurar Access Gateway para eliminar algunos o todos los grupos de datos al cerrar la sesión. Es posible que desee retener algunos de esos datos, como datos que se completan automáticamente, contraseñas almacenadas e historiales, especialmente si está utilizando su computadora personal. Los datos se categorizan en los siguientes tres grupos para ayudarlo a eliminarlos de manera selectiva:

Ninguno. Si selecciona este nivel, no se selecciona ninguno de los grupos de datos.

Sólo explorador. Si selecciona este nivel, puede establecer Access Gateway para que elimine uno o varios de los siguientes grupos de datos:

  • Contraseñas y datos que se completan automáticamente almacenados por el explorador
  • Historial y direcciones Web escritos en la barra de direcciones
  • Cookies en caché del explorador y archivos temporales

Todo. Si selecciona este nivel, puede establecer Access Gateway para que elimine todos los datos temporales generados por el equipo.

Configuración del proceso de limpieza

El administrador del sistema es quien controla el proceso de limpieza. El cuadro de diálogo de limpieza sólo aparece si el administrador configuró Access Gateway para que muestre ese cuadro de diálogo. Además, el administrador puede configurar Access Gateway para que elimine grupos de datos específicos de su equipo al salir de la sesión. Las opciones que corresponden a estos grupos de datos están desactivadas en la ficha Lista del cuadro de diálogo Citrix Windows Cleanup. Las opciones restantes se activan o desactivan en función del nivel de limpieza elegido.

  1. En el cuadro de diálogo Citrix Windows Cleanup, haga clic en Lista.
  2. Seleccione o desmarque la casilla de verificación junto al grupo de datos.

Visualización de los registros de limpieza

Access Gateway Plug-in registra toda la actividad de limpieza en un archivo que se almacena en el disco duro. El archivo enumera las acciones realizadas y los archivos eliminados.

  1. En la ficha Resumen, haga clic en Ver registro.
