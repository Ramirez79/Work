Cómo trabajar con Access Interface

En Access Gateway se encuentra Access Interface, que es la página de inicio, tal como se muestra en la siguiente figura. En este tema se enumeran los sitios Web internos y los archivos compartidos a los que se accede con mayor frecuencia en la organización. El administrador configura los enlaces que aparecen en Sitios Web empresariales o Puntos compartidos empresariales. Puede crear sus propios marcadores y visualizarlos en Sitios Web personales o Puntos compartidos personales. En esta sección se describen las tareas de configuración que se pueden realizar en Access Interface.

Figura 1. Página de inicio predeterminada de Access Gateway denominada Access Interface
Nota: Access Interface es la página de inicio predeterminada incluida en Access Gateway. El administrador del sistema puede utilizar otra página de inicio; por lo tanto, es posible que no vea la página Access Interface cuando inicie sesión.
