Inicio de sesión en Access Interface

Es posible iniciar sesión en la página de inicio de diferentes maneras, según el modo en que el administrador del sistema haya configurado el dispositivo de Access Gateway. Es posible que aparezca la página de inicio de Access Interface o una página personalizada instalada por el administrador del sistema. Si escribe una dirección Web después de iniciar sesión, puede ver una de las siguientes tres opciones:

  • Citrix XenApp
  • Acceso sin cliente
  • Acceso de red

Citrix XenApp proporciona acceso a las aplicaciones que residen en la red de la organización. El administrador del sistema puede publicar cualquier tipo de aplicación, como Microsoft Word o Outlook.

Si seleccionó Citrix XenApp, deberá iniciar sesión y aparecerá una lista de las aplicaciones publicadas.

Si inicia sesión mediante Acceso sin cliente o con Access Gateway Plug-in (al hacer clic en Acceso de red) y su administrador configuró las aplicaciones publicadas en Access Gateway, la página de inicio de Access Interface aparece con sus aplicaciones publicadas en el panel izquierdo, como se muestra en la siguiente ilustración:
