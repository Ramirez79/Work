Guía del usuario de Access Gateway Plug-in para Windows

Antes de iniciar sesión mediante Citrix Access Gateway Plug-in para Windows, revise esta guía del usuario para conocer cómo funcionan las conexiones y cómo acceder a los recursos de red en la red segura.

Esta guía del usuario está dirigida a aquellos usuarios que inician sesión en la red interna a través de un dispositivo Access Gateway. En esta guía se supone que el dispositivo Access Gateway está conectado a una red existente y que el administrador del sistema ha configurado el dispositivo para establecer conexiones de usuarios.
