Convenciones de la documentación

La documentación de productos Citrix utiliza las siguientes convenciones tipográficas.

Presentación o convención Descripción
Controles de la interfaz del usuario Nombres de los botones, casillas, opciones u otros controles en la interfaz del usuario.
Nombres de comandos Nombres de comandos como ipconfig.
Nombre de variables Indicadores variables para información que provee. Por ejemplo, nombre_de_archivo significa que deberá introducir el nombre real del archivo.
Términos Términos que se presentan por primera vez o que se enfatizan.
Ejemplos de código Texto que se muestra en el código o en un archivo de texto.
{ llaves } En un comando, una serie de elementos, uno de los cuales es necesario. Por ejemplo, { yes | no } significa que debe escribir yes o no. Las llaves no se escriben, sólo el elemento.
[ corchetes ] En un comando, elementos opcionales. Por ejemplo, [/ping] significa que puede escribir /ping en el comando. Los corchetes no se escriben, sólo el elemento.
| (barra vertical) En un comando, un separador entre elementos entre llaves o corchetes. Por ejemplo, { /hold | /release | /delete } significa que se debe escribir /hold o /release o /delete.
... (puntos suspensivos) Los elementos anteriores del comando pueden repetirse. Por ejemplo, /route:nombre_del_dispositivo[,…] significa que se pueden introducir varios nombres_de_dispositivos separados por comas.
