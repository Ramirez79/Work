Códigos de error de sesión de Access Gateway

Los siguientes códigos de error aparecen en la ventana de sesión de Access Gateway. Estos códigos pueden utilizarse para resolver problemas con Access Gateway.

Código de errores Descripción

0001-1000

Funcionamiento normal

1001-2000

Error interno

2001-3000

Errores de Access Gateway Plug-in

3001-4000

Errores del explorador

En la siguiente tabla se describen los códigos de errores y los mensajes que se muestran en la sesión de Access Gateway, así como la acción que debe tomar en respuesta al mensaje.

Código Mensaje Explicación Acción
0001 Cargando... Este mensaje indica que Access Gateway Plug-in está cargando la configuración antes de establecer la sesión de Access Gateway. Ninguna
0002 Conexión establecida. Para finalizar esta sesión, haga clic con el botón secundario del mouse en el icono de Access Gateway y, a continuación, haga clic en Cierre de sesión. Este mensaje aparece cuando Access Gateway Plug-in se conecta correctamente. Ninguna
0003 Saliendo... Este mensaje aparece cuando el usuario hace clic en Cierre de sesión en el menú de Access Gateway. Ninguna
0004 Su sesión ha caducado. No está conectado. Este mensaje de error aparece cuando caduca la sesión del dispositivo de usuario. Ninguna
0004 No ha iniciado sesión. Este mensaje de error aparece cuando Access Gateway Plug-in no está conectado. Ninguna
0005 Su sesión va a caducar en <número> segundos. Este mensaje de error aparece cuando una sesión se configura para una desconexión forzada. Ninguna
0006 Degradación de Access Gateway Plug-in de <NúmerodeVersión> a <NúmerodeVersión>. Access Gateway está instalando una versión anterior del software. Ninguna
0006 Actualización de Access Gateway Plug-in de <NúmerodeVersión> a <NúmerodeVersión>. Access Gateway Plug-in está actualizando a una nueva versión del software. Ninguna
1003 Error en la asignación de memoria. Access Gateway Plug-in no tiene suficiente memoria. Cuando aparezca este error, cierre sesión, reinicie Access Gateway Plug-in y vuelva a iniciar sesión. Además, notifique este error al personal de asistencia técnica o al administrador del sistema.
1004 Se produjo un error interno. Para obtener más información, comuníquese con el administrador. Access Gateway Plug-in no puede llamar a Windows API correctamente. Ninguna
1006 Se produjo un error interno. Para obtener más información, comuníquese con el administrador. Error en la comprobación de seguridad del dispositivo de usuario al escanear la lista de procesos de Windows. Inicie sesión con una cuenta de administrador.
1007 Se produjo un error interno. Para obtener más información, comuníquese con el administrador. Error en la comprobación de seguridad del dispositivo de usuario al abrir un servicio del sistema de Windows. Inicie sesión con una cuenta de administrador.
1008 Se produjo un error interno. Para obtener más información, comuníquese con el administrador. Error en Access Gateway Plug-in. Reinicie Access Gateway Plug-in y envíe el archivo de seguimiento de depuración al personal de asistencia técnica o al administrador del sistema.
1010 Error en el inicio de sesión. El usuario no puede iniciar sesión. Ninguna
1011 Citrix Access Gateway Plug-in no pudo descargar la configuración correcta. Access Gateway Plug-in no puede descargar la configuración de Access Gateway correctamente. Compruebe el estado de la red y, a continuación, comuníquese con el administrador del sistema.
1012 No se pudo iniciar Access Gateway Plug-in. Para más información, consulte el registro de conexión. Access Gateway Plug-in no pudo establecer una conexión. Para obtener más información, compruebe el registro de conexión y realice los cambios necesarios. Encuentre el error en el registro de conexión y, a continuación, notifíquelo al personal de asistencia técnica o al administrador del sistema.
1013 Error en el análisis de la configuración. Consulte el registro de conexión para obtener más información. Se produjo un error en la configuración de Access Gateway. Comuníquese con el administrador del sistema o el personal de asistencia técnica.
1014 El dispositivo cliente no pudo resolver la dirección Web de Access Gateway. Access Gateway Plug-in no pudo resolver el nombre de dominio. Modifique el archivo HOSTS o solicite al administrador del sistema que cambie o arregle la configuración.
1015 No se pudo establecer una conexión segura. Access Gateway Plug-in no pudo establecer una conexión segura. Comuníquese con el administrador del sistema o el personal de asistencia técnica.
1016 Error al degradar Access Gateway Plug-in de <NúmerodeVersión> a <NúmerodeVersión>. Se produjo un error al instalar una versión anterior de Access Gateway Plug-in. Comuníquese con el administrador del sistema o el personal de asistencia técnica.
1016 Error al actualizar Access Gateway Plug-in de <NúmerodeVersión> a <NúmerodeVersión>. Citrix Access Gateway Plug-in no pudo actualizar a la versión más reciente. Comuníquese con el administrador del sistema o el personal de asistencia técnica.
2001 Su sesión de Access Gateway ha caducado y no está conectado. Este mensaje indica que la sesión de Access Gateway del usuario ha caducado. Cierre sesión en Access Gateway Plug-in y vuelva a iniciar sesión.
2003 Hay un problema de configuración en Access Gateway. Este mensaje indica que la configuración de Access Gateway no es correcta. Comuníquese con el administrador del sistema para configurar Access Gateway correctamente.
2004 Debe instalar software de seguridad de punto final. Este mensaje indica que al menos una de las aplicaciones de seguridad de punto final requerida no está instalada. Comuníquese con el administrador del sistema para instalar el software de seguridad requerido.
2005 Debe actualizar el software de seguridad de punto final. Este mensaje indica que no es la versión correcta del software de seguridad de punto final. Comuníquese con el administrador del sistema para actualizar el software de seguridad requerido.
2006 No está activado el software de seguridad requerido. Este mensaje indica que el software de seguridad de punto final no está activado. Inicie el software de seguridad.
2007 Esta versión de Citrix Access Gateway Plug-in está actualizada. Inicie sesión nuevamente. Este mensaje indica que la versión de Access Gateway Plug-in en el dispositivo de usuario no coincide con Access Gateway. Cierre la sesión y, a continuación, inicie sesión nuevamente.
2008 No coinciden las versiones de Citrix Access Gateway Plug-in y Access Gateway. Para actualizar, inicie sesión mediante el explorador Web. Access Gateway Plug-in no coincide con la versión de Access Gateway. Los usuarios pueden actualizar automáticamente al iniciar sesión en el explorador Web. Desinstale Access Gateway Plug-in, reinicie el dispositivo de usuario e inicie sesión nuevamente para instalar el plug-in.
2008 Esta versión de Citrix Access Gateway Plug-in está actualizada. Inicie sesión nuevamente. La actualización de Access Gateway Plug-in es correcta, pero no se activó automáticamente. Cierre la sesión y, a continuación, inicie sesión nuevamente.
2009 El servidor proxy requiere autenticación no compatible. Un parámetro proxy de reenvío local requiere autenticación. Access Gateway Plug-in no admite todos los tipos de autenticación compatibles con proxy. Ninguna
2010 Error en la autenticación del servidor proxy, inicie sesión nuevamente. Un parámetro proxy de reenvío local requiere autenticación. Este mensaje de error aparece cuando el usuario no puede suministrar un nombre de usuario o contraseña válidos. Ninguna
2011 Access Gateway no pudo validar el certificado de seguridad. El certificado de cliente no es el certificado correcto. El certificado puede almacenarse en un explorador Web o en una tarjeta inteligente. Access Gateway Plug-in no puede detectar el certificado requerido. Comuníquese con el administrador del sistema o el personal de asistencia técnica para que le suministren el certificado correcto.
2012 Error en el inicio de Access Gateway Plug-in. No se pudo iniciar Access Gateway Plug-in. Para ello, es necesario que el usuario inicie sesión como administrador. Inicie sesión con Access Gateway Plug-in mediante una cuenta de administrador.
2013 Error en la lectura de los parámetros de proxy en el explorador Web. Access Gateway Plug-in no leyó los parámetros de proxy en el explorador. Ninguna
2014 Su versión de sistema operativo no admite Access Gateway Plug-in. Para obtener más información, comuníquese con el servicio de asistencia técnica o con el administrador del sistema. El usuario intenta instalar Access Gateway Plug-in en una versión del sistema operativo que no es compatible. Ninguna
2014 Es necesario detener la aplicación <NombredelaAplicación>. Access Gateway está configurado para evitar que el dispositivo de usuario ejecute la aplicación especificada. Detenga la aplicación.
2015 Este inicio de sesión supera la cantidad máxima de usuarios permitidos. Todas las licencias de Access Gateway están en uso. Comuníquese con el administrador del sistema o el personal de asistencia técnica.
2016 Access Gateway no se encuentra disponible. No se puede establecer la conexión con Access Gateway. Ninguna
2017 Configuración del mensaje de error personalizado. El administrador del sistema del usuario configuró el mensaje de error. El mensaje no puede tener más de 100 caracteres. Este mensaje de error aparece cuando se produce un error en el análisis de punto final. Comuníquese con el administrador del sistema o el personal de asistencia técnica.
2017 Su equipo no cuenta con el software de seguridad necesario para conectarse con Access Gateway. Comuníquese con el servicio de asistencia técnica o con el administrador del sistema. Si se produce un error en la comprobación de seguridad del dispositivo de usuario y el administrador no utiliza el mensaje de error personalizado, aparece el mensaje de error predeterminado. Comuníquese con el administrador del sistema o el personal de asistencia técnica.
2018 Access Gateway no detectó actividad en el teclado o en el mouse. La sesión ha caducado. La sesión caducó porque no se detectó actividad en el dispositivo de usuario durante un tiempo determinado. Cierre la sesión y, a continuación, inicie sesión nuevamente.
2019 No se pudo establecer la conexión con Access Gateway debido a un error en el análisis de seguridad del cliente. Access Gateway requiere que el dispositivo de usuario cuente con productos de software, procesos o archivos específicos. Si el dispositivo de usuario no cumple los requisitos del análisis de seguridad, los usuarios no pueden iniciar sesión. Detenga Access Gateway Plug-in y configure el dispositivo de usuario con los parámetros adecuados para pasar el análisis de seguridad.
2020 La interfaz Web se utiliza para las conexiones de usuario. Utilice Internet Explorer para iniciar sesión. La interfaz Web sólo es compatible en Internet Explorer. Utilice Internet Explorer para conectarse a la interfaz Web.
3001 Ya ha iniciado sesión en Access Gateway. Ha iniciado sesión en Access Gateway mediante Access Gateway Plug-in. Ninguna
3002 No ha iniciado sesión en Access Gateway. No se puede encontrar la cookie de sesión de Access Gateway. Compruebe que el usuario haya iniciado sesión. Inicie sesión mediante Access Gateway Plug-in.
3003 Access Gateway Plug-in es compatible con Internet Explorer versión 4 y versiones posteriores. Este mensaje indica que Access Gateway no puede detectar la presencia de Internet Explorer en el dispositivo de usuario. También puede indicar que el dispositivo de usuario tiene instalada una versión más antigua de Internet Explorer que no es compatible. Si está utilizando Windows Vista, Internet Explorer 7 es la única versión compatible para este sistema operativo. Actualice Internet Explorer y vuelva a iniciar sesión.
3006 No se pudo iniciar Endpoint Analysis Plug-in. Comuníquese con el administrador del sistema o el personal de asistencia técnica. Error en el inicio del complemento. Comuníquese con el administrador del sistema o el personal de asistencia técnica.
