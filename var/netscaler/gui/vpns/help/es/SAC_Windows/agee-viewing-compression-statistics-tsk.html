Visualización de estadísticas de compresión

La ficha Compresión muestra estadísticas sobre las velocidades de compresión del tráfico TCP de la sesión actual de Access Gateway, detalladas por conexión. Las columnas de esta ficha incluyen las siguientes estadísticas.

  • Puerto: el número de puerto en el que se comunica la conexión.
  • Datos no comprimidos: tamaño de los datos antes de aplicar la compresión.
  • Datos comprimidos: tamaño de los datos después de aplicar la compresión.
  • Ahorro de ancho de banda: ahorro aproximado de ancho de banda (expresado como porcentaje) cuando se utiliza la compresión. Esta estadística se calcula al restar el tamaño de los datos comprimidos del tamaño real y dividir el resultado por el tamaño de datos real.
  • Velocidad de compresión: se basa en el tamaño de datos real en comparación con el tamaño de datos comprimidos.
Nota: en ocasiones, el ahorro de ancho de banda puede mostrar un valor negativo. Esto sucede con las aplicaciones en las que los datos transmitidos se envían en partes muy pequeñas y con otras aplicaciones en las que los datos se comprimen antes del envío.

  2. Haga clic en la ficha Compresión.
