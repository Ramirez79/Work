Cambio de parámetros en el cuadro de diálogo Opciones avanzadas

En el cuadro de diálogo Access Gateway Plug-in, puede cambiar los siguientes parámetros:

  • Dirección IP o dirección Web para Access Gateway
  • Parámetros del servidor proxy
  • Advertencias de certificados de seguridad
Nota: estos parámetros sólo se pueden cambiar si se configuró Access Gateway Plug-in para iniciar sesión mediante el cuadro de diálogo Access Gateway, en lugar del explorador Web. Para obtener más información, consulte Creación de conexiones a través de Access Gateway Plug-in.

Configuración de la dirección Web de Access Gateway

Cuando Access Gateway Plug-in esté configurado, debe utilizar la dirección IP de Access Gateway configurada previamente para establecer la conexión. Puede configurar el plug-in para conectarse a otro dispositivo.

  1. En el área de notificación, haga clic con el botón secundario del mouse en el icono de Access Gateway Plug-in y, a continuación, haga clic en Inicio de sesión.
  2. En el cuadro de diálogo de inicio de sesión de Citrix Access Gateway, haga clic con el botón secundario del mouse en cualquier lugar del cuadro de diálogo y, a continuación, seleccione Opciones avanzadas.
  3. En Configuración de Citrix Access Gateway, en Dirección Web, escriba la dirección Web y, a continuación, haga clic en Aceptar.

    La dirección Web puede ser una dirección IP, como 192.168.1.2, o bien, una dirección Web como https://ag1.miempresa.com.

Configuración de servidores proxy para Access Gateway Plug-in

Un servidor proxy es un equipo que se encuentra entre su dispositivo y los servidores de la red interna. Los servidores proxy interceptan las solicitudes del explorador Web dirigidas al servidor de la red interna para verificar si el servidor proxy puede procesar la página Web solicitada. Si el servidor proxy no puede procesar la solicitud, la envía al servidor de la red segura.

Cuando se configura manualmente el servidor proxy, se desactiva la detección automática de los parámetros proxy.

  1. En el área de notificación, haga clic con el botón secundario del mouse en el icono de Access Gateway y, a continuación, haga clic en Inicio de sesión.
  2. En el cuadro de diálogo de inicio de sesión de Citrix Access Gateway, haga clic con el botón secundario del mouse en cualquier lugar del cuadro de diálogo y, a continuación, seleccione Opciones avanzadas.
  3. En Parámetros proxy, seleccione Configurar manualmente el servidor proxy.
  4. En Dirección IP y Puerto, escriba la dirección IP y el número de puerto.
Nota: para acceder al cuadro de diálogo de inicio de sesión y a Opciones avanzadas a fin de configurar los parámetros proxy, debe cerrar la sesión de Access Gateway.

Inicio de sesión con una contraseña secundaria

Es posible que algunos dispositivos de Access Gateway requieran que inicie sesión mediante dos tipos de autenticación. Estos tipos de autenticación pueden incluir su nombre de usuario, contraseña y número de identificación personal (PIN) seguido por un número de identificador, como un número de token de RSA SecurID.

El parámetro predeterminado del cuadro de diálogo Access Gateway se utiliza para mostrar los campos de inicio de sesión del nombre de usuario y de la contraseña. Puede configurar Access Gateway Plug-in para que muestre el campo de contraseña secundaria.

  1. En el área de notificación, haga clic con el botón secundario del mouse en el icono de Access Gateway y, a continuación, haga clic en Abrir.
  2. Haga clic con el botón secundario del mouse en cualquier lugar del cuadro de diálogo y, a continuación, haga clic en Mostrar contraseña secundaria.
Nota: si no necesita mostrar el campo de la contraseña secundaria, en el cuadro de diálogo Access Gateway, haga clic con el botón secundario del mouse en cualquier lugar y, a continuación, haga clic en Ocultar contraseña secundaria.
