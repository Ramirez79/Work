Mise à niveau d’Access Gateway Plug-in

Access Gateway Plug-in pour Windows se met automatiquement à niveau dès qu’une nouvelle version du logiciel est disponible. Lorsque vous ouvrez une session Access Gateway, le boîtier détecte la version du plug-in installée sur votre machine. Si la version du plug-in ne correspond pas à la version présente sur Access Gateway, le logiciel est mis à niveau automatiquement sur votre ordinateur. Une fois la mise à niveau terminée, vous pouvez ouvrir une session Access Gateway et vous connecter aux ressources réseau du réseau interne.

Si votre administrateur système configure Access Gateway pour rechercher sur l'ordinateur la présence de logiciels, fichiers, processus et autres éléments, Endpoint Analysis Plug-in s'installe automatique sur l'ordinateur et analyse celui-ci pour effectuer la recherche. Endpoint Analysis Plug-in se met également à niveau automatiquement dès qu’une nouvelle version est disponible.

Si vous pouvez vous connecter à plusieurs boîtiers Access Gateway, la version du logiciel exécuté sur chacun d'eux peut être différente. Par exemple, la version d’Access Gateway exécutée sur le boîtier ag1 peut être plus récente que celle du boîtier ag2. Si vous vous êtes connecté au boîtier ag1, fermez la session et connectez-vous au boîtier ag2. Access Gateway Plug-in et Endpoint Analysis Plug-in effectueront automatiquement une rétrogradation vers la version associée au boîtier ag2.
