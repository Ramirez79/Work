Création de connexions à l’aide d’Access Gateway Plug-in

Pour pouvoir vous connecter à Access Gateway Plug-in et l’utiliser, votre administrateur système doit vous fournir les informations ci-après :

  • Adresse Web d’Access Gateway, par exemple, https://AccessGatewayFQDN/.
  • Configuration requise pour exécuter le plug-in, déterminée par votre administrateur système. La configuration requise peut inclure un logiciel antivirus ou un pare-feu personnel installé sur votre ordinateur.

En fonction de la configuration de votre ordinateur, il est possible que vous deviez également satisfaire les conditions supplémentaires suivantes :

  • Pour installer Access Gateway Plug-in, vous devez être administrateur local ou membre du groupe d’administrateurs autorisés à installer des programmes sur votre ordinateur.
  • Si vous avez installé un pare-feu personnel sur votre ordinateur, celui-ci peut afficher un message vous invitant à autoriser la connexion lors de votre première connexion au plug-in. Si vous recevez ce message d’invite, autorisez toujours la connexion. Pour plus d’informations sur l'autorisation de connexions, consultez la documentation du fabricant.

Connexion à l’aide d’une adresse Web

Si vous vous connectez à partir d’une adresse Web, vous êtes soit invité à ouvrir une session, ou soit directement redirigé vers une page de portail dans laquelle vous pouvez vous connecter à l'aide d'Access Gateway Plug-in.

Si Access Gateway est configuré pour vous inviter à ouvrir une session avant d'établir une connexion au plug-in, entrez votre nom d’utilisateur et votre mot de passe, puis ouvrez une session. Une page Web vous permettant de télécharger et d’installer le plug-in s’affiche. Une fois Access Gateway Plug-in installé, la connexion vous donne un accès total aux ressources réseau que vous êtes autorisé à utiliser.

Téléchargement et installation d’Access Gateway Plug-in

Pour établir une connexion sécurisée lors de la première utilisation, ouvrez une session Access Gateway en utilisant un navigateur Web. Contactez votre administrateur pour obtenir l’adresse Web et les informations d’ouverture de session. Le format standard d’une adresse Web est le suivant : https://ag.nomsociété.com.

  1. Dans un navigateur Web, entrez l’adresse Web d’Access Gateway.
  2. Tapez vos nom d'utilisateur et mot de passe, puis cliquez sur Ouvrir une session.
  3. Cliquez sur Accès réseau pour installer le plug-in.

Une fois le téléchargement terminé, le plug-in se connecte et affiche un message dans la zone de notification de la barre des tâches. Vous pouvez également ouvrir une session en cliquant sur l’icône d’Access Gateway figurant dans la zone de notification.

Connexion à partir de la boîte de dialogue Access Gateway Plug-in

Si vous souhaitez vous connecter à partir d’Access Gateway Plug-in et non à partir d’un navigateur Web, vous pouvez configurer le plug-in afin qu’il affiche la boîte de dialogue d’ouverture de session lorsque vous cliquez sur l’icône figurant dans la zone de notification.

Remarque : pour configurer les paramètres d’Access Gateway Plug-in, vous devez ouvrir une session.
  1. Dans la zone de notification, cliquez avec le bouton droit de la souris sur l’icône d’Access Gateway et cliquez sur Configurer Access Gateway.
  2. Cliquez sur l’onglet Profil, puis sur Modifier le profil.
  3. Dans l’onglet Options, cliquez sur Utiliser Access Gateway Plug-in pour l’ouverture de session.

Pour ouvrir une session, cliquez deux fois sur l’icône d’Access Gateway sur le bureau. Vous pouvez également cliquer avec le bouton droit de la souris sur l’icône Access Gateway dans la zone de notification de la barre des tâches, puis cliquer sur Ouvrir une session. Pour plus d’informations sur la configuration d’Access Gateway Plug-in, consultez la section Modification des paramètres de la boîte de dialogue Options avancées.
