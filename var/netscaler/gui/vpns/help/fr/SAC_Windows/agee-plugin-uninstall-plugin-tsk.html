Désinstallation d’Access Gateway Plug-in

Vous pouvez désinstaller Access Gateway Plug-in à l’aide de l’option Ajouter ou supprimer des programmes du Panneau de configuration. Pour désinstaller le plug-in, vous devez ouvrir une session administrateur.
  1. Cliquez sur Démarrer > Panneau de configuration.
  2. Cliquez sur Ajouter ou supprimer des programmes.
  3. Sous Programmes actuellement installés, cliquez sur Citrix Access Gateway Plug-in, puis sur Supprimer.
