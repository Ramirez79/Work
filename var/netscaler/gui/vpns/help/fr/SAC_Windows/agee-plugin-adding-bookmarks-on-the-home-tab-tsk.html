Ajout de signets dans l’onglet Accueil

Votre administrateur système peut ajouter des signets à l'interface d'accès. Ils s'affichent sous forme de liens sous Sites Web d'entreprise. Vous pouvez également créer vos propres signets pour les ressources réseau les plus utilisées. Ces signets peuvent être des liens à des sites intranet, tels qu'un site SharePoint, ou à des sites Web Internet ou des partages de fichiers sur le réseau interne. Les liens que vous créez s'affichent sous Partages de fichiers personnels.

  1. Cliquez sur Ajouter.
  2. Dans le champ Nom, entrez le nom du lien.
  3. Dans le champ Adresse, entrez l’adresse du site Web ou le chemin d’accès au réseau du serveur Web interne.
  4. Dans le champ Description, entrez une description pour le lien et cliquez sur Ajouter.
Remarque : Access Gateway peut distinguer automatiquement les adresses Web des chemins d'accès aux fichiers réseau en fonction du format dans lequel vous les avez entrés ; par exemple, http://www.monentreprise.com ou \\serveur\nomdepartage. Lorsque vous créez un lien, il est inutile de préciser le type de ressource.

Suppression d’un signet

Vous pouvez supprimer les signets répertoriés sous Sites Web personnels, mais pas ceux qui figurent sous Sites Web d’entreprise.

  1. Cliquez sur Supprimer.
  2. Sélectionnez le signet et cliquez sur Supprimer.

Utilisation de l’onglet E-mail

L’onglet E-mail vous permet d’accéder à vos e-mails à partir de Microsoft Outlook Web Access. Lorsque vous cliquez sur l'onglet, votre messagerie apparaît comme si vous utilisiez une version locale de Outlook.

Pour utiliser Outlook Web Access, votre administrateur système doit configurer l'application.

Connexion aux partages de fichiers à partir de l’onglet Transfert de fichiers

L'onglet Transfert de fichiers vous permet de vous connecter au réseau interne et d'accéder à des ressources partagées.

  1. Dans l'interface d'accès, cliquez sur l’onglet Transfert de fichiers.

Ouverture de l’onglet Transfert de fichiers à l’aide de l’icône d'Access Gateway

  1. Dans la zone de notification, cliquez avec le bouton droit de la souris sur l’icône d’Access Gateway et cliquez sur Transférer les fichiers.

Les sections suivantes traitent des divers composants de l’onglet Transfert de fichiers.

Configuration des paramètres dans le panneau supérieur

Le panneau supérieur de la fenêtre du navigateur comporte plusieurs boutons qui vous permettent d’effectuer diverses tâches de stockage et de transfert des fichiers.

  • Ouvrir une session. Cliquez sur ce bouton pour ouvrir une session sur le réseau interne ou sur un ordinateur particulier du réseau.
  • Haut. Cliquez sur ce bouton pour accéder au dossier précédent.
  • Actualiser. Cliquez sur ce bouton pour actualiser le contenu du dossier actif.
  • Nouveau dossier. Cliquez sur ce bouton pour créer un dossier.
  • Télécharger. Cliquez sur ce bouton pour télécharger le fichier sélectionné à partir du serveur distant.
  • Télécharger (en amont). Cliquez sur ce bouton pour télécharger le fichier sélectionné de la machine utilisateur sur un dossier du serveur distant.
  • Supprimer. Cliquez sur ce bouton pour supprimer le fichier sélectionné de l’ordinateur distant.
  • Renommer. Cliquez sur ce bouton pour modifier le nom du fichier ou du dossier.
  • Fermer la session. Cliquez sur ce bouton pour vous déconnecter du serveur distant.

Affichage de dossiers et de fichiers dans le volet gauche

Les serveurs, leurs répertoires et la structure de ces derniers s’affichent sous forme d’arborescence dans le volet gauche. Cliquez sur l’icône plus (+) pour afficher les dossiers.

Connexion aux ressources réseau dans le volet droit

Le volet droit affiche la fenêtre Serveur de fichiers. Cette fenêtre vous permet d’ouvrir une session sur un serveur de fichiers du réseau interne. Pour accéder au serveur de fichiers, entrez l’adresse du partage de fichiers. Vous pouvez également entrer votre nom d’utilisateur, votre mot de passe et le nom de domaine, si nécessaire. Si vous avez accès au partage de fichiers après avoir ouvert une session Access Gateway, il est possible que vous n'ayez pas besoin d’entrer vos nom d’utilisateur et mot de passe ou le nom de domaine.

  1. Dans la zone de notification, cliquez avec le bouton droit de la souris sur l’icône d’Access Gateway et cliquez sur Transférer les fichiers.
  2. Dans le champ Adresse, entrez le nom du partage de fichiers.
  3. Si vos informations d’identification sont requises, cliquez sur Entrer informations d’identification et effectuez les étapes 4 à 7. Dans le cas contraire, cliquez sur Ouvrir une session.
  4. Dans le champ Nom d’utilisateur, entrez votre nom d’utilisateur.
  5. Dans le champ Mot de passe, entrez votre mot de passe.
  6. Dans le champ Domaine, entrez un nom de domaine valide.
  7. Cliquez sur Ouvrir une session.

Si aucun domaine spécifique n’est attribué au serveur distant, laissez le champ Domaine vide.

Remarque : si vous laissez ce champ vide, vous serez connecté au réseau interne et non à un serveur particulier.

Les sous-dossiers et les fichiers s’affichent dans le volet droit. L’emplacement du dossier actif apparaît dans le champ Adresse.
