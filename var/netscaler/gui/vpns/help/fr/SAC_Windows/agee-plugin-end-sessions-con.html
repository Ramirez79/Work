Fin des sessions Access Gateway Plug-in

Vous pouvez mettre fin à votre session avec Access Gateway Plug-in de l'une des façons suivantes :

  • en fermant la session Access Gateway ;
  • en quittant la session.

Pour fermer une session Access Gateway

Lorsque vous fermez une session, celle-ci se termine et l’icône d'Access Gateway reste dans la zone de notification.

Il existe deux façons de fermer une session Access Gateway :

  • en cliquant sur Fermer la session dans l'interface d'accès ;
  • en cliquant avec le bouton droit de la souris sur l'icône Access Gateway dans la zone de notification, puis en cliquant sur Fermer la session.

Pour quitter la session

Lorsque vous quittez une session, celle-ci se termine et l’icône d'Access Gateway disparaît de la zone de notification.

  • Cliquez avec le bouton droit de la souris sur l'icône Access Gateway dans la zone de notification, puis cliquez sur Quitter.
