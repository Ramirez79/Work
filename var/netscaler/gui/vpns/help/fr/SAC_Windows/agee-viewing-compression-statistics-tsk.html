Affichage des statistiques de compression

L'onglet Compression affiche des statistiques sur le taux de compression du trafic TCP au cours de la session Access Gateway actuelle. Ces statistiques sont ventilées par connexions individuelles. Les colonnes de cet onglet comportent les statistiques suivantes :

  • Port. Nombre de ports de communication associés à la connexion.
  • Données non compressées. Taille des données avant compression.
  • Données compressées. Taille des données après compression.
  • Économie de bande passante. Économies approximatives de bande passante lors d’une compression (en pourcentage). Cette statistique est calculée en soustrayant la taille des données compressées à leur taille réelle, puis en divisant le résultat par la taille réelle des données.
  • Taux de compression. Taux de compression basé sur la différence entre la taille réelle des données et leur taille une fois celles-ci compressées.
Remarque : les économies de bande passante peuvent parfois s’afficher en valeurs négatives. C’est le cas pour les applications dans lesquelles les données sont transmises en très petites portions et pour celles dans lesquelles les données sont compressées avant d’être envoyées.
  1. Dans la zone de notification, cliquez avec le bouton droit de la souris sur l’icône d’Access Gateway et cliquez sur Configurer Access Gateway.
  2. Cliquez sur l’onglet Compression.
