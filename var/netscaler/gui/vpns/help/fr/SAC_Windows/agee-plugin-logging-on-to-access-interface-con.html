Connexion à l'interface d'accès

En fonction de la façon dont votre administrateur système a configuré le boîtier Access Gateway, la connexion à la page d’accueil peut se faire de plusieurs manières. En fonction de ce que votre administrateur système a installé, l'interface d'accès ou une page d'accueil personnalisée peut s'afficher. Si vous entrez une adresse Web après avoir ouvert une session, les trois options suivantes seront disponibles :

  • Citrix XenApp
  • Accès sans client
  • Accès réseau

Citrix XenApp permet d’accéder aux applications hébergées sur le réseau de votre entreprise. Votre administrateur système peut publier tout type d’application (Microsoft Word ou Outlook, par exemple).

Si vous avez sélectionné Citrix XenApp, vous êtes connecté et la liste de vos applications publiées s’affiche.

Si vous vous connectez avec l’accès sans client ou Access Gateway Plug-in (en cliquant sur Accès réseau) et que votre administrateur a configuré des applications publiées sur Access Gateway, la page d’accueil de l'interface d'accès s’affiche avec vos applications publiées dans le panneau gauche, comme illustré ci-dessous :
