Analyse de l'ordinateur pour détecter la présence des logiciels

Votre administrateur système peut configurer Access Gateway pour détecter la présence de logiciels, de fichiers, de processus et d’autres éléments sur votre ordinateur. Ce processus est appelé analyse de point de terminaison. Lorsque vous ouvrez une session pour la première fois, Endpoint Analysis Plug-in est automatiquement installé et analyse l'ordinateur pour s’assurer de la présence des logiciels ou des processus requis. Si certains logiciels ou processus requis sont absents, il est possible que vous ne puissiez pas ouvrir de session. Lorsque vous ouvrez une session, vous pouvez choisir d’analyser l'ordinateur ou d’ignorer l’analyse. Il est préférable d'autoriser l’analyse. En l’ignorant, il se peut que vous n’arriviez pas à ouvrir une session Access Gateway ou à vous connecter aux ressources du réseau interne.

Endpoint Analysis Plug-in peut également analyser l'ordinateur après l’ouverture de session pour s’assurer que les logiciels requis sont toujours présents et qu’il s’agit de la dernière version requise par votre réseau. En cas de non-conformité, votre session peut se terminer.
