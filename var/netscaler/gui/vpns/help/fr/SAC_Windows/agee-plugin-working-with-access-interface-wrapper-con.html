Utilisation de l'interface d'accès

L'interface d'accès est la page d’accueil d’Access Gateway. Elle est illustrée dans la figure ci-après. Cette rubrique dresse la liste des sites Web et partages de fichiers internes auxquels les utilisateurs accèdent le plus souvent au sein de votre organisation. L'administrateur configure les liens visibles sous Sites Web d'entreprise ou Partages de fichiers d'entreprise. Vous pouvez créer vos propres signets qui apparaîtront sous Sites Web personnels ou Partages de fichiers personnels. Cette section examine les tâches de configuration que vous pouvez réaliser dans l'interface d'accès.

Figure 1. Page d’accueil par défaut d’Access Gateway, également appelée interface d'accès.
Remarque : l'interface d'accès est la page d’accueil par défaut fournie avec Access Gateway. Votre administrateur système peut utiliser une autre page d’accueil. Par conséquent, il est possible que l'interface d'accès ne soit pas visible lorsque vous ouvrez une session.
