Nettoyage de votre ordinateur à la fin d'une session

Pendant une session, des fichiers temporaires sont créés sur votre ordinateur. Access Gateway est doté d’une fonctionnalité de nettoyage vous permettant de les supprimer. Votre administrateur système active cette fonctionnalité.

Vous pouvez sélectionner les éléments suivants et les supprimer de l'ordinateur lors du nettoyage :

  • Access Gateway Plug-in ;
  • certificats utilisés pour l’authentification ;
  • applications utilisées pendant la session ;
  • mots de passe et données entrées automatiquement ;
  • historique et adresses Web entrées dans la barre d’adresses ;
  • cookies et fichiers temporaires.

Recherches d’informations dans l’onglet Synthèse

L'onglet Synthèse affiche les informations suivantes sur votre session :

  • le nombre total d’entrées de registre modifiées ;
  • le nombre total de cookies installés ;
  • le nombre total d’applications utilisées.

Configuration du niveau de nettoyage

Vous pouvez configurer Access Gateway pour supprimer une partie ou l'ensemble des jeux de données lors de la fermeture de la session. Vous pouvez avoir besoin de conserver certaines données, telles que les données de saisie semi-automatique, les mots de passe stockés et l’historique, en particulier si vous utilisez votre ordinateur personnel. Pour vous permettre d’effectuer une suppression sélective, les données se divisent en trois catégories :

Aucun. Lorsque vous sélectionnez ce niveau, les jeux de données ne sont pas supprimés.

Navigateur Web uniquement. Lorsque ce niveau est sélectionné, vous pouvez configurer Access Gateway pour supprimer un ou plusieurs des jeux de données suivants :

  • mots de passe et données entrées automatiquement stockés par le navigateur ;
  • historique et adresses Web entrées dans la barre d’adresses ;
  • cookies et fichiers temporaires du cache du navigateur.

Tous les éléments. Lorsque ce niveau est sélectionné, vous pouvez configurer Access Gateway pour supprimer toutes les données temporaires générées par votre ordinateur.

Configuration du processus de nettoyage

Votre administrateur système contrôle le processus de nettoyage. La boîte de dialogue de nettoyage n’apparaît que si l’administrateur a configuré Access Gateway pour vous permettre de l’afficher. Celui-ci peut également configurer Access Gateway pour supprimer des jeux de données spécifiques de votre ordinateur lorsque vous fermez la session. Les options correspondant à ces données sont désactivées dans l’onglet Liste de la boîte de dialogue Nettoyage des fenêtres Citrix. Les autres options sont activées ou désactivées en fonction du niveau de nettoyage que vous choisissez.

  1. Dans la boîte de dialogue Nettoyage des fenêtres Citrix, cliquez sur Liste.
  2. Activez ou désactivez la case à cocher en regard du jeu de données.

Visualisation des journaux de nettoyage

Access Gateway Plug-in journalise toutes les activités de nettoyage dans un fichier stocké sur le disque dur. Ce fichier répertorie l’action effectuée et les fichiers supprimés.

  1. Dans l’onglet Synthèse, cliquez sur Visualiser le journal.
