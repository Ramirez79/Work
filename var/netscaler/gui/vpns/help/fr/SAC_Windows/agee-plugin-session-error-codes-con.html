Codes d’erreur de la session Gateway Access

Les codes d’erreur suivants s’affichent dans la fenêtre de session Access Gateway. Ils vous permettent de résoudre les problèmes liés à Access Gateway.

Code d'erreur Description

0001-1000

Fonctionnement normal

1001-2000

Erreur interne

2001-3000

Erreurs d’Access Gateway Plug-in

3001-4000

Erreurs du navigateur

Le tableau suivant dresse la liste des codes d'erreur et des messages qui s'affichent dans la session Access Gateway, ainsi que toute action à entreprendre.

Code Message Explication Action
0001 Chargement... Ce message indique qu’Access Gateway Plug-in charge la configuration avant l'établissement de la session Access Gateway. Aucun.
0002 Connexion établie. Pour fermer cette session, cliquez avec le bouton droit de la souris sur l’icône d’Access Gateway, puis cliquez sur Fermer la session. Ce message s’affiche lorsque la connexion Access Gateway Plug-in est établie. Aucun.
0003 Fin de la session... Ce message s’affiche lorsque l’utilisateur clique sur Fermer la session dans le menu Access Gateway. Aucun.
0004 Votre session a expiré, vous n’êtes pas connecté. Ce message d’erreur s’affiche lorsque la session de la machine utilisateur a expiré. Aucun.
0004 Vous n’êtes pas connecté. Ce message d’erreur s’affiche lorsqu’Access Gateway Plug-in n’est pas connecté. Aucun.
0005 Votre session va expirer dans <nombre> secondes. Ce message d’erreur s’affiche lorsque l’expiration forcée de la session est configurée. Aucun.
0006 Rétrogradation d’Access Gateway Plug-in de la version <NuméroVersion> vers la version <NuméroVersion>. Access Gateway installe une version plus ancienne du logiciel. Aucun.
0006 Mise à niveau d’Access Gateway Plug-in de la version <NuméroVersion> vers la version <NuméroVersion>. Access Gateway Plug-in est mis à niveau vers une nouvelle version. Aucun.
1003 Échec d’affectation de la mémoire. La mémoire est insuffisante pour exécuter Access Gateway Plug-in. Si cette erreur s’affiche, fermez la session, redémarrez Access Gateway Plug-in, puis ouvrez une nouvelle session. Signalez cette erreur au service d’assistance technique ou à votre administrateur système.
1004 Une erreur interne s’est produite. Pour plus d'informations, contactez votre administrateur. Access Gateway Plug-in ne peut pas appeler l’API Windows. Aucun.
1006 Une erreur interne s’est produite. Pour plus d'informations, contactez votre administrateur. Échec de la vérification de la sécurité de la machine utilisateur lors de l’analyse de la liste des processus Windows. Ouvrez une session à l'aide d'un compte d'administrateur.
1007 Une erreur interne s’est produite. Pour plus d'informations, contactez votre administrateur. Échec de la vérification de la sécurité de la machine utilisateur lors de l’ouverture d’un service système Windows. Ouvrez une session à l'aide d'un compte d'administrateur.
1008 Une erreur interne s’est produite. Pour plus d'informations, contactez votre administrateur. L'exécution d'Access Gateway Plug-in a échoué. Redémarrez Access Gateway Plug-in et envoyez le fichier de trace du débogage au service d’assistance technique ou à votre administrateur système.
1010 Votre connexion a échoué. L’utilisateur n’a pas réussi à ouvrir une session. Aucun.
1011 Access Gateway Plug-in n’a pas réussi à télécharger la configuration correcte. Access Gateway Plug-in n’a pas réussi à télécharger la configuration d’Access Gateway. Vérifiez l’état du réseau et contactez votre administrateur système.
1012 Impossible de démarrer Access Gateway Plug-in. Pour plus d’informations, consultez le journal des connexions. Access Gateway Plug-in n’a pas réussi à établir une connexion. Pour plus d’informations, consultez le journal des connexions et apportez les modifications nécessaires. Recherchez l’erreur dans le journal des connexions, puis signalez-la au service d’assistance technique ou à votre administrateur système.
1013 Échec de l’analyse de la configuration. Pour plus d'informations, consultez le journal des connexions. Une erreur de configuration s’est produite sur Access Gateway. Contactez votre service d’assistance ou votre administrateur système.
1014 La machine cliente n’a pas réussi à résoudre l’adresse Web d’Access Gateway. Access Gateway Plug-in n’a pas réussi à résoudre le nom de domaine. Modifiez le fichier HOSTS ou demandez à votre administrateur système de modifier ou de corriger la configuration.
1015 Impossible d’établir la connexion sécurisée. Access Gateway Plug-in n’a pas réussi à établir une connexion sécurisée. Contactez votre service d’assistance ou votre administrateur système.
1016 Impossible de rétrograder Access Gateway Plug-in de la version <NuméroVersion> vers la version <NuméroVersion>. L’installation d’une version antérieure d’Access Gateway Plug-in a échoué. Contactez votre service d’assistance ou votre administrateur système.
1016 Impossible de mettre à niveau Access Gateway Plug-in de la version <NuméroVersion> vers la version <NuméroVersion>. Access Gateway Plug-in n’a pas réussi à effectuer la mise à niveau vers la version la plus récente. Contactez votre service d’assistance ou votre administrateur système.
2001 Votre session Access Gateway a expiré et vous n’êtes pas connecté. Ce message indique que la session Access Gateway de l'utilisateur a expiré. Fermez la session à partir d’Access Gateway Plug-in, puis ouvrez une nouvelle session.
2003 Access Gateway a rencontré un problème de configuration. Ce message indique qu’Access Gateway n’est pas correctement configuré. Contactez votre administrateur système pour configurer correctement Access Gateway.
2004 Vous devez installer un logiciel de sécurité de point de terminaison. Ce message indique qu’au moins une des applications de sécurité de point de terminaison requises n’est pas installée. Contactez votre administrateur système pour installer le logiciel de sécurité requis.
2005 Vous devez mettre à niveau le logiciel de sécurité de point de terminaison. Ce message indique que la version du logiciel de sécurité de point de terminaison est inappropriée. Contactez votre administrateur système pour mettre à niveau le logiciel de sécurité.
2006 Le logiciel de sécurité requis n’est pas activé. Ce message indique que le logiciel de sécurité de point de terminaison est désactivé. Démarrez le logiciel de sécurité.
2007 Cette version d’Access Gateway Plug-in est actualisée. Ouvrez une nouvelle session. Ce message indique que la version d'Access Gateway Plug-in présente sur la machine utilisateur ne correspond pas à celle d'Access Gateway. Fermez la session, puis ouvrez-en une nouvelle.
2008 Les versions d’Access Gateway Plug-in et d’Access Gateway ne correspondent pas. Pour mettre à niveau, ouvrez une session à l’aide du navigateur Web. La version d’Access Gateway Plug-in ne correspond pas à celle d’Access Gateway. Les utilisateurs peuvent effectuer une mise à niveau automatique en ouvrant une session sur le navigateur Web. Désinstallez Access Gateway Plug-in, redémarrez la machine utilisateur et ouvrez une nouvelle session pour installer le plug-in.
2008 Cette version d’Access Gateway Plug-in est actualisée. Ouvrez une nouvelle session. Access Gateway Plug-in a été mis à niveau, mais ne s’est pas activé automatiquement. Fermez la session, puis ouvrez-en une nouvelle.
2009 L’authentification exigée par le serveur proxy n’est pas prise en charge. Un paramètre de proxy direct local requiert une authentification. Les types d’authentification requis par les serveurs proxy ne sont pas tous pris en charge par Access Gateway Plug-in. Aucun.
2010 Échec de l’authentification du serveur proxy. Ouvrez une nouvelle session. Un paramètre de proxy direct local requiert une authentification. Ce message d’erreur s’affiche lorsque l’utilisateur indique un nom d’utilisateur ou un mot de passe non valide. Aucun.
2011 Access Gateway n’a pas réussi à valider le certificat sécurisé. Le certificat client est inapproprié. Vous pouvez stocker le certificat sur un navigateur Web ou sur une carte à puces. Access Gateway Plug-in ne peut pas détecter le certificat requis. Contactez le service d’assistance technique ou votre administrateur système pour obtenir le certificat client adéquat.
2012 Échec de démarrage d'Access Gateway Plug-in. Impossible de démarrer Access Gateway Plug-in. Pour corriger ce problème, l’utilisateur doit ouvrir une session administrateur. Ouvrez une session Access Gateway Plug-in en utilisant un compte administrateur.
2013 Impossible de lire les paramètres du proxy sur le navigateur Web. Access Gateway Plug-in n’a pas réussi à lire les paramètres du proxy sur le navigateur. Aucun.
2014 Access Gateway Plug-in n’est pas pris en charge sur cette version de votre système d’exploitation. Pour plus d'informations, contactez votre service d’assistance ou votre administrateur système. L’utilisateur tente d’installer Access Gateway Plug-in sur une version non prise en charge du système d’exploitation. Aucun.
2014 Vous devez arrêter l’application <NomApplication>. Access Gateway est configuré pour empêcher la machine utilisateur d’exécuter l’application spécifiée. Arrêtez l’application.
2015 Cette ouverture de session dépasse le nombre maximal d’utilisateurs autorisés. Toutes les licences sur Access Gateway sont utilisées. Contactez votre service d’assistance ou votre administrateur système.
2016 Access Gateway n’est pas disponible. Impossible d'établir une connexion à Access Gateway. Aucun.
2017 Message d’erreur personnalisé configuré. Ce message d’erreur est configuré par l'administrateur système e l'utilisateur et ne doit pas comporter plus de 100 caractères. Il s’affiche lorsque l’analyse de point de terminaison échoue. Contactez votre service d’assistance ou votre administrateur système.
2017 Le logiciel de sécurité requis pour se connecter à Access Gateway n’est pas installé sur l’ordinateur. Contactez votre service d’assistance ou votre administrateur système. Ce message d’erreur s’affiche par défaut si la sécurité de la machine utilisateur ne peut pas être vérifiée et que l’administrateur système n’utilise pas le message d’erreur personnalisé. Contactez votre service d’assistance ou votre administrateur système.
2018 Access Gateway n’a détecté aucune activité de la souris ou du clavier. La session a expiré. La session a expiré car aucune activité n’a été détectée sur la machine utilisateur pendant un intervalle de temps défini. Fermez la session, puis ouvrez-en une nouvelle.
2019 La connexion à Access Gateway ne peut pas être établie en raison de l’échec de l’analyse du point de terminaison. Access Gateway requiert la présence de logiciels, processus ou fichiers sur la machine utilisateur. Si la machine utilisateur ne répond pas aux exigences de l'analyse de point de terminaison, les utilisateurs ne peuvent pas ouvrir de session. Arrêtez Access Gateway Plug-in et configurez les paramètres adéquats sur la machine utilisateur de manière à ce que l'analyse de point de terminaison réussisse.
2020 L’Interface Web est utilisée pour les connexions utilisateur. Pour ouvrir une session, utilisez Internet Explorer. L’Interface Web est uniquement prise en charge sur Internet Explorer. Utilisez Internet Explorer pour vous connecter à l’Interface Web.
3001 Vous êtes déjà connecté à Access Gateway. Vous avez ouvert une session Access Gateway à partir d'Access Gateway Plug-in. Aucun.
3002 Vous n’êtes pas connecté à Access Gateway. Le cookie de la session Access Gateway est introuvable. Vérifiez si l’utilisateur a ouvert une session. Ouvrez une session en utilisant Access Gateway Plug-in.
3003 Access Gateway Plug-in prend en charge toutes les versions d’Internet Explorer à partir de la version 4. Ce message indique qu'Access Gateway ne peut pas détecter la présence d'Internet Explorer sur la machine utilisateur. Cela peut également signifier que la version d’Internet Explorer installée sur la machine utilisateur est une ancienne version non prise en charge. Si vous utilisez Windows Vista, Internet Explorer 7 est la seule version prise en charge par le système d’exploitation. Effectuez une mise à niveau d’Internet Explorer, puis ouvrez une nouvelle session.
3006 Échec du démarrage de Endpoint Analysis Plug-in. Contactez votre service d’assistance ou votre administrateur système. Échec de démarrage du plug-in. Contactez votre service d’assistance ou votre administrateur système.
