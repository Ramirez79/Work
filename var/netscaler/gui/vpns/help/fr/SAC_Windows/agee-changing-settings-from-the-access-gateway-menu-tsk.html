Modification des paramètres à partir du menu Access Gateway

Lorsque vous êtes connecté, vous pouvez modifier les paramètres en cliquant avec le bouton droit de la souris sur l’icône d’Access Gateway dans la zone de notification, puis en sélectionnant un élément dans le menu d'Access Gateway. À partir de ce menu, vous pouvez effectuer les opérations suivantes :

  • ouvrir l'interface d'accès ou la page d’accueil configurée par votre administrateur système ;
  • exécuter l’utilitaire de transfert de fichiers ;
  • modifier les paramètres de configuration ;
  • ouvrir le journal des connexions ;
  • afficher le message Access Gateway Plug-in actuel ;
  • ouvrir l’aide en ligne ;
  • fermer la session et quitter Access Gateway Plug-in.

Votre administrateur peut configurer Access Gateway Plug-in et vous interdire l’accès à l'interface d'accès, à l’utilitaire de transfert de fichiers ou aux paramètres de configuration. Dans ce cas, ces éléments n’apparaissent pas dans le menu.

Ouverture de l'interface d'accès

L'interface d'accès de Citrix vous permet de tester la connexion à d’autres ordinateurs, de configurer des signets, de transférer des fichiers et de vous connecter à une messagerie Web, telle qu’Outlook Web Access. Pour plus d’informations sur la page d’accueil, veuillez consulter la section Utilisation de l'interface d'accès.

Votre administrateur système peut désactiver l'interface d'accès et utiliser une autre page Web en guise de page d’accueil. Cette section décrit l’utilisation de l'interface d'accès.

  1. Dans la zone de notification, cliquez avec le bouton droit de la souris sur l’icône d’Access Gateway et cliquez sur Accueil.

Affichage et modification des informations et des paramètres d’Access Gateway Plug-in

Grâce au menu accessible à partir de l’icône d’Access Gateway dans la zone de notification, vous pouvez ouvrir la boîte de dialogue Configuration de Citrix Access Gateway. Vous pouvez consulter des informations sur la connexion Access Gateway et configurer les paramètres pour les connexions.

Remarque : vous devez être connecté pour pouvoir ouvrir la boîte de dialogue.
  1. Cliquez avec le bouton droit de la souris sur l’icône d'Access Gateway dans la zone de notification et cliquez sur Configurer Access Gateway.

Affichage des statistiques de connexion

Dans la boîte de dialogue Configuration, vous pouvez effectuer les opérations suivantes :

  • afficher les statistiques de connexion ;
  • afficher votre profil, tel que le boîtier Access Gateway auquel vous êtes connecté, les réseaux auxquels vous pouvez vous connecter et d’autres paramètres de configuration ;
  • configurer les informations de journalisation pour la connexion Access Gateway ;
  • afficher les informations sur la compression des connexions.

L’onglet Général affiche les informations relatives à la connexion. Ces informations peuvent s’avérer utiles pour le personnel d’assistance technique en cas de problèmes de connexion.

Remarque : votre administrateur peut avoir configuré Access Gateway de manière à interdire l’accès aux statistiques de connexion.
  1. Dans la zone de notification, cliquez avec le bouton droit de la souris sur l’icône d’Access Gateway et cliquez sur Configurer Access Gateway.
  2. Cliquez sur l’onglet Général.

Modification des paramètres sur l’onglet Profil

Dans la boîte de dialogue Configuration, sur l’onglet Profil, vous pouvez modifier les paramètres de connexion suivants :

  • split tunneling, split DNS et accès au réseau local ;
  • domaine et adresse IP nécessaires pour se connecter aux ressources spécifiques du réseau interne ;
  • réseaux pour activer ou désactiver l'accès ;
  • paramètres de l'ordinateur pour activer la possibilité de se connecter avec Access Gateway Plug-in à chaque fois sans utiliser de navigateur Web ;
  • avertissements relatifs au certificat de sécurité.
