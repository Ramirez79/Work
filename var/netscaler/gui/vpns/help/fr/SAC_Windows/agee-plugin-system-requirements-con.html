Configuration requise pour Access Gateway Plug-in

Access Gateway Plug-in s’exécute sur les systèmes d’exploitation suivants :

  • Windows XP (32 bits)
  • Windows Vista (32 bits et 64 bits)
  • Windows 7 (32 bits et 64 bits)

Les navigateurs Web pris en charge sont les suivants :

  • Internet Explorer
  • Firefox
