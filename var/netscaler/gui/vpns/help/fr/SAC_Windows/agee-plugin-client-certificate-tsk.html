Ouverture de session avec un certificat client

Vous pouvez ouvrir une session Access Gateway à l’aide d’un certificat client. Lorsque vous ouvrez une session Access Gateway, les détails du certificat sont comparés aux informations configurées sur Access Gateway par votre administrateur système. S’ils correspondent, vous pouvez ouvrir une session. Dans le cas contraire, la connexion peut être refusée.

Access Gateway peut authentifier un certificat client stocké dans l’un des emplacements suivants :

  • Dans le magasin de certificats du système d’exploitation Windows de votre ordinateur. Dans ce cas, le certificat client est installé séparément dans le magasin de certificats à l’aide de la console Microsoft Management Console.
  • Dans une carte à puce ou un jeton matériel. Dans ce cas, le certificat est intégré à la carte à puce et sa lecture est effectuée par un lecteur de cartes à puce connecté au réseau.
  • Dans une carte d'accès que le Ministère américain de la défense utilise pour l'identification et l'authentification.

Pour installer le certificat client sur l'ordinateur, suivez les instructions fournies par votre administrateur système ou par le service d’assistance.

Si plusieurs certificats clients sont installés sur l'ordinateur, Access Gateway Plug-in vous invite à sélectionner le certificat approprié pour ouvrir une session.

Si vous ouvrez une session en utilisant Internet Explorer ou la boîte de dialogue Access Gateway Plug-in, le certificat client utilisé provient du magasin de certificats de Windows. Si vous ouvrez une session en utilisant le navigateur Web Firefox, vous devez importer le certificat dans Firefox.

Pour importer un certificat client dans Firefox

  1. Ouvrez le navigateur Web Firefox.
  2. Dans le menu, cliquez sur Outils, puis sur Options.
  3. Cliquez sur Avancé.
  4. Dans la boîte de dialogue Gestionnaires des certificats, cliquez sur Vos certificats, puis sur Importer.
  5. Accédez au certificat stocké sur votre ordinateur, puis cliquez sur Ouvrir.

    Un mot de passe pour le certificat peut vous être demandé. Contactez votre administrateur système ou le service d’assistance pour obtenir le mot de passe.

  6. Cliquez sur OK.

Pour plus d’informations sur l’importation de certificats dans Firefox, consultez le programme d’aide de Firefox.
