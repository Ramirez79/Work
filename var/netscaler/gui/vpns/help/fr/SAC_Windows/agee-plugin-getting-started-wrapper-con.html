Guide de démarrage d’Access Gateway Plug-in

Access Gateway est un boîtier matériel qui permet d’établir une communication entre votre ordinateur et un réseau d’entreprise distant. Pour ce faire, il crée une connexion sécurisée entre votre ordinateur et Access Gateway. Cela vous permet d’accéder aux ressources stratégiques de l'entreprise, telles que la messagerie, les systèmes de fichiers partagés et les applications.
