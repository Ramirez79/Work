Configuration du split tunneling

Lorsque le split tunneling est activé, Access Gateway filtre le trafic en utilisant l’adresse IP du réseau de destination. Le trafic destiné au réseau de votre entreprise est envoyé via Access Gateway tandis que le reste du trafic est envoyé vers votre réseau local (LAN) ou Internet. Le split tunneling limite le trafic réseau qui transite via Access Gateway en fonction de l'adresse IP.

Par exemple, vous vous connectez à un site Web intranet au sein du réseau de votre organisation et la requête est envoyée à Access Gateway. Si vous vous connectez à un site Web externe, tel que cnn.com, le trafic réseau ne transite pas via Access Gateway.

Le split tunneling propose trois options :

  • Activé. Lorsque le split tunneling est activé, Access Gateway Plug-in compare l’adresse IP et le port de destination avec les valeurs configurées par l’administrateur système sur Access Gateway. Si l’une des valeurs correspond, les paquets sont envoyés au réseau distant via Access Gateway. Si aucune valeur ne correspond, les paquets sont transférés vers votre LAN.
  • Désactivé. Si vous choisissez l'option Désactivé, le split tunneling est désactivé et Access Gateway Plug-in envoie l’ensemble du trafic au réseau distant via Access Gateway.
  • Inverser. Lorsque l’option Inverser est activée, les connexions Internet et les demandes adressées à votre réseau local sont envoyées via Access Gateway. Les connexions aux ressources du réseau interne ne sont pas envoyées via Access Gateway. Cette option est généralement utilisée lorsqu’Access Gateway est hébergé sur le réseau interne et que vous vous connectez depuis votre bureau.
Important : si le split tunneling est désactivé sur Access Gateway, les contrôles correspondant au split tunneling et au split DNS sont désactivés dans Access Gateway Plug-in et vous ne pouvez pas modifier les paramètres. L’ensemble du trafic réseau est envoyé via Access Gateway.
  1. Cliquez avec le bouton droit de la souris sur l’icône d'Access Gateway Plug-in dans la zone de notification et cliquez sur Configurer Access Gateway.
  2. Cliquez sur l’onglet Profil, puis sur Modifier le profil.
  3. Sur l’onglet Connexions, sous Split tunneling, sélectionnez l’option souhaitée et cliquez sur OK.
