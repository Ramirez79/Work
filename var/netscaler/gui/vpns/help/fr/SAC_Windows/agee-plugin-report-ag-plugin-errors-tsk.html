Génération de rapports d’erreurs à l’aide d’Access Gateway Plug-in

Vous pouvez configurer Access Gateway Plug-in pour consigner toutes les erreurs dans un fichier texte. Access Gateway Plug-in consigne l'ensemble de ses principales activités dans un fichier journal. Ces fichiers sont stockés sur votre ordinateur. Vous pouvez envoyer les fichiers journaux à votre service d’assistance ou à votre administrateur système.

Sous Windows XP, les fichiers journaux se trouvent dans le répertoire %systemdrive%\Documents and Settings\All Users\Application Data\Citrix\AGEE et dans %systemdrive%\Documents and Settings\%NomUtilisateur%\Local Settings\Application Data\Citrix\AGEE.

Sous Windows Vista et Windows 7, les fichiers journaux se trouvent dans le répertoire %systemdrive%\ProgramData\Citrix\AGEE et dans %systemdrive%\Users\%NomUtilisateur%\AppData\Local\Citrix\AGEE. Votre administrateur système peut utiliser ces fichiers journaux pour résoudre les problèmes liés à Access Gateway Plug-in.

Vous pouvez définir le niveau de journalisation d'Access Gateway Plug-in, comme suit :

  • Ne pas enregistrer les messages de débogage.
  • Enregistrer les messages de niveau d’événement.
  • Enregistrer uniquement les statistiques du client.
  • Enregistrer les messages de débogage détaillés.
  1. Cliquez avec le bouton droit de la souris sur l’icône d'Access Gateway Plug-in dans la zone de notification et cliquez sur Configurer Access Gateway.
  2. Cliquez sur l’onglet Suivi, sélectionnez le niveau de journalisation et cliquez sur OK.

Affichage des fichiers journaux

Les fichiers journaux fournissent des informations sur les problèmes que vous pouvez rencontrer dans Access Gateway Plug-in. En cas de problème, ces informations peuvent s’avérer utiles pour le personnel d’assistance technique.

  1. Cliquez avec le bouton droit de la souris sur l’icône d'Access Gateway Plug-in dans la zone de notification et cliquez sur Configurer Access Gateway.
  2. Cliquez sur l’onglet Suivi.
  3. Sous Journal de suivi du client, cliquez sur Afficher le fichier journal.
