Fonctionnement d’Access Gateway

Pour vous connecter à votre réseau d'entreprise interne, vous devez ouvrir une session Access Gateway. Pour ce faire, utilisez Access Gateway Plug-in. Si vous essayez de vous connecter au réseau interne, installez le plug-in sur l'ordinateur avant d’ouvrir la session.

Access Gateway Plug-in doit être installé sur l'ordinateur lors de la première ouverture de session. Une fois le plug-in installé, vous pouvez ouvrir une session à l'aide de l’icône située sur votre bureau ou vous connecter en utilisant une page de portail Web.

Lorsqu'Access Gateway Plug-in est téléchargé sur l'ordinateur et qu’une connexion est établie, ce dernier est relié à Access Gateway par le biais d’un canal de communication sécurisé, vous permettant ainsi d’accéder aux ressources du réseau interne que vous êtes autorisé à utiliser.

Votre administrateur système peut également configurer Access Gateway Plug-in pour s’assurer que certains pare-feu personnels et logiciels antivirus sont en cours d'exécution sur l'ordinateur.
