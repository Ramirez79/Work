Modification des paramètres de la boîte de dialogue Options avancées

Dans la boîte de dialogue Access Gateway Plug-in, vous pouvez modifier les paramètres suivants :

  • l'adresse IP ou l'adresse Web d'Access Gateway ;
  • les paramètres du serveur proxy ;
  • les avertissements relatifs aux certificats de sécurité.
Remarque : vous pouvez uniquement modifier ces paramètres si vous avez configuré Access Gateway Plug-in de manière à ce qu'il se connecte à l'aide de la boîte de dialogue d’Access Gateway plutôt qu'à l'aide d'un navigateur Web. Pour plus d'informations, veuillez consulter la section Création de connexions à l’aide d’Access Gateway Plug-in.

Définition de l’adresse web d’Access Gateway

Une fois Access Gateway Plug-in configuré, utilisez l’adresse IP préconfigurée d’Access Gateway pour vous connecter. Vous pouvez également configurer la connexion du plug-in à un autre boîtier.

  1. Dans la zone de notification, cliquez avec le bouton droit de la souris sur l’icône d'Access Gateway Plug-in et cliquez sur Ouvrir une session.
  2. Dans la boîte de dialogue d'ouverture de session de Citrix Access Gateway, cliquez avec le bouton droit de la souris n’importe où dans la boîte de dialogue, puis cliquez sur Options avancées.
  3. Sous Configuration de Citrix Access Gateway, dans Adresse Web, entrez l'adresse Web et cliquez sur OK.

    L’adresse Web peut être une adresse IP, telle que 192.168.1.2, ou une adresse Web, telle que https://ag1.masociété.com.

Configuration des serveurs Proxy pour Access Gateway Plug-in

Un serveur proxy est un ordinateur qui se trouve entre votre machine et les serveurs du réseau interne. Les serveurs proxy interceptent les requêtes émanant de votre navigateur Web à destination du serveur du réseau interne pour savoir s'ils peuvent exécuter la page Web requise. Si le serveur proxy ne peut pas répondre à la requête, il l'envoie au serveur qui se trouve sur le réseau interne.

Lorsque vous configurez manuellement un serveur proxy, la détection automatique des paramètres de proxy est désactivée.

  1. Dans la zone de notification, cliquez avec le bouton droit de la souris sur l’icône d'Access Gateway et cliquez sur Ouvrir une session.
  2. Dans la boîte de dialogue d'ouverture de session de Citrix Access Gateway, cliquez avec le bouton droit de la souris n’importe où dans la boîte de dialogue, puis cliquez sur Options avancées.
  3. Sous Paramètres du proxy, sélectionnez Configurer le serveur proxy manuellement.
  4. Dans Adresse IP et Port, entrez l’adresse IP et le numéro de port.
Remarque : pour accéder à la boîte de dialogue d’ouverture de session et aux Options avancées de manière à configurer les paramètres du proxy, vous devez fermer la session Access Gateway.

Ouverture de session avec un mot de passe secondaire

Pour certains boîtiers Access Gateway, l’ouverture de session peut nécessiter deux types d’authentification. Cela peut impliquer d'entrer votre nom d’utilisateur, votre mot de passe et un numéro d’identification personnel suivi d’un numéro de jeton, tel qu'un numéro de jeton RSA SecurID.

La boîte de dialogue Access Gateway affiche par défaut les champs d’ouverture de session pour vos nom d’utilisateur et mot de passe. Vous pouvez configurer Access Gateway Plug-in pour afficher le champ du mot de passe secondaire.

  1. Dans la zone de notification, cliquez avec le bouton droit de la souris sur l’icône d'Access Gateway et cliquez sur Ouvrir.
  2. Cliquez avec le bouton droit de la souris n’importe où dans la boîte de dialogue et cliquez sur Afficher le mot de passe secondaire.
Remarque : si vous n'avez pas besoin d'afficher le champ de mot de passe secondaire, dans la boîte de dialogue Access Gateway, cliquez avec le bouton droit de la souris n’importe où dans la boîte de dialogue et cliquez sur Masquer le mot de passe secondaire.
