Notes

  • For a website: add the full address from http://.
    For example: http://intranet.corp.com
  • For a Filesystem: add server and share folder starting from \\ in the Address field.
    For example: \\fileserver\sharefolder
  • Length of Name and Address is limited to 256 characters.
