I. Introduction
Citrix Access Gateway Plug-in is client software for Linux 
Ubuntu(12.04 and 14.04) (32-bit & 64-bit),SUSE(SP1,SP3,SLED) 
(32-bit & 64-bit) that enables secure connectivity through 
Access Gateway, Enterprise Edition.

II. Package List
---------------
nsgclient32.deb          Linux vpn client debian package for ubuntu 32 bit
nsgclient64.deb          Linux vpn client debian package for ubuntu 64 bit
nsginstaller32.deb       Linux vpn client installer for ubuntu 32 bit
nsginstaller64.deb       Linux vpn client installer for ubuntu 64 bit
nsgclient64sled12.rpm    Linux vpn client rpm package for SLED 64 bit
nsgclient32susesp1.rpm   Linux vpn client rpm package for SUSE SP1 32 bit
nsgclient64susesp1.rpm   Linux vpn client rpm package for SUSE SP1 64 bit 
nsgclient32susesp3.rpm   Linux vpn client rpm package for SUSE SP3 32 bit
nsgclient64susesp3.rpm   Linux vpn client rpm package for SUSE SP3 64 bit

III. Client-Versions
clientversions.xml file contains version info about 
above package lists. Checkversion module will parse
clientversions file for version compatibility and 
return result accordingly.

IV. Installation
For ubuntu : Install as you would normally install a debian package.
For SUSE   : Install as you would normally install a rpm package.
